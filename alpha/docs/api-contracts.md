# Alpha API 语义

具体 endpoint、参数和响应以 `alpha/api/routes/`、Pydantic 模型与路由测试为准，本文只保留跨客户端业务约定。

## 公共边界

HTTP 与 WebSocket 均验证服务 Bearer 凭据，回环监听不代替认证。system 路径只供专用生命周期调用。业务错误保留 HTTP 状态与结构化 detail，不能与传输失败混同；Python 不返回 UI 文案、颜色或图标。

公开值必须可用 JSON 表达，NaN、Infinity 和内部 ORM/provider 对象不能进入响应。跨层协议修改同步验证前端解析，普通领域接口变化不扩张 Rust 通用代理。

## 行情查询

- 公开复权为 none、forward、backward，内部别名不泄漏。日线、周线表示无时区交易日；盘中时间带显式 UTC 偏移。
- 证券详情提供 IANA 时区、涨跌颜色约定、成交量单位、价格跳动和真实覆盖，前端不猜测。
- start/end 范围与 before 历史分页互斥。before 是排他上界，响应升序并给出实际范围与下一游标，调用方不能自行构造。
- bars 只查询数据库，不混入 MarketFeed 瞬时值。分页使用同一覆盖范围的复权锚点，不能每页重新定基。
- reference_close/reference_time 独立于 bars。日周线取锚点前一根完成 K 线；盘中取本交易时段之前最近完成日线，周期与复权口径一致，缺少可靠前序数据返回 null。

## 指标

studies 提供权威 definition，批量 calculate 接收数据键、区间和有界实例，不接受前端原始 bars。参数校验先于读取行情；后端一次读取显示范围及所需 warmup，回测与图表共用公式。

输出与显示 bars 一一对应、严格升序，warmup 不足为 null。计算异常、非有限输入和长度错位使整次请求失败，不能返回部分实例或输出。类型、数量与参数限制以 schema 为准。

## 任务与同步

长任务立即返回任务 ID，结果和日志独立查询；事件和 HTTP 使用同一完整任务快照，详见 [事件运行时](event-runtime.md)。回测列表合并回测任务与持久结果，同 ID 不重复，优化任务不混入。

日线同步同一时间只运行一个任务，可按服务端给出的有界证券集合定向重试。overview 只返回轻量状态与最近质量快照；异常明细可截断，但总异常数与受影响标的数独立保留，前端不能自行扩大重试集合。非法批次拒绝写入，合法部分覆盖及写后不一致进入质量报告，详见 [行情存储](market-data.md)。

## 自选

全部自选是去重的关注集合；证券可以同时属于多个自定义分组，各组独立保存手动顺序和置顶顺序。取消置顶保留普通顺序位置。全部自选中移除证券会清理所有分组关系；自定义分组中移除只改变当前关系。删除分组不取消关注。

复制保留来源，移动在同一事务中增加目标关系并移除来源关系，不影响其他组。目标已有成员不重复添加、不改变其位置或置顶状态；新成员按来源手动显示顺序追加到目标普通区。批量转组返回事务内统计的处理数量与目标已有数量，前端不根据旧列表估算。全部自选只能添加到分组，不能作为移动来源。分组名称去除首尾空白并唯一。

重排使用相邻证券与前后方向或首尾位置，不上传整表；置顶区和普通区不通过拖动相互转换。事务读取当前成员后解析位置，目标分组、成员或同区域锚点失效时返回冲突，客户端重新查询权威快照。新关注、成员移除与显式置顶状态可重复提交；分组创建和移动遇到未知提交结果时应先查询快照。

日线摘要批量覆盖当前组全部证券，以有界并发读取最近二十根前复权收盘线及最近原始收盘价，附带数据所属日期和市场元数据。涨幅是相对上一根可用日线原始收盘价的变化；当前存储无交易所除权参考价，检测到复权跳变时涨幅为空，不能用小图相邻点收益代替。无数据、无参考价、局部读取失败均不伪造零值；单个分片读取失败不阻塞其他证券摘要。摘要不作为自选成员数据持久化。


## 标的概览

证券快照只读目录和最近一条未复权日线，不触发同步、外部行情或派生指标计算。行情日期来自该条日线，不使用目录更新时间代替；无日线返回空快照，证券不存在返回 404。缺失数值保持空值，零成交量保留，存储中非正的限价占位值作为缺失返回。该查询独立于图表的周期与复权配置。
