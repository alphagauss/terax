# 事件与任务运行时

EventEngine 按事件类型和可选业务键，在分发线程中顺序执行同步 callback；它不拥有领域状态、网络或持久化。公共 Gateway 只暴露显式白名单事件，内部事件不会自动成为远程协议。

## 有限任务

唯一 TaskManager 管理有终态的回测、优化和同步子进程。普通进度在子进程节流，阶段变化与终态立即报告；先更新完整快照，再发 task.updated。领域 result handler 保存成功前不能发布 succeeded。

任务快照 revision 单调递增，同 ID 再运行也不能倒退。取消有界等待后升级终止，服务关闭不留下无所有者进程；日志、队列和快照有界。事件不是恢复源，成功后读取领域结果，重启不能假设内存任务仍存在。

## 公共订阅

唯一 events 连接按 event + key 订阅，未指定 key 表示整个公共事件族；行情必须提供完整证券、周期和复权键。具体协议版本、字段和上限以路由 schema 为准。

前端一个 WebView 复用一条连接，相同 selector 引用计数。慢连接关闭后重连、重放订阅并重新查询 HTTP 权威状态，不提供全局 sequence 或历史重放。

## 行情与未来交易

MarketFeed 的首个 owner 为数据键启动唯一上游任务，最后 owner 释放时取消并清除最新值。每键只保留最新完整 bar 去重，拒绝时间倒退；当前 volume/amount 为累计值，新时间确认上一根完成。

历史来自 HTTP，前端按时间替换或追加实时值。重新订阅由 Provider 发布最新值，live 仅表示上游链路健康，不表示开市，也不代表账户和订单新鲜度。

模拟盘应消费未复权 quote/tick，不能用图表复权 K 线撮合。账户、订单、成交与持仓由 PaperTradingEngine 持有并先保存再发事件；长期对象不塞入有限 TaskManager。详细回放未来使用独立事件，不把大结果塞入任务快照。
