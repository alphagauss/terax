# 行情存储与复权

## 存储与写入

业务数据位于绝对 data_dir。主库保存证券资料、覆盖与复权等目录信息，K 线按周期和时间分片；物理命名与表结构以 storage 实现为准。

- 只持久化原始未复权价格。主行情 upsert 与日线限价补写是不同写入模式。
- 同一数据库文件写入串行，不承诺跨分片原子性；读取空范围不创建分片。
- 正常写入同步更新 overview，批量导入可延后但结束须重建。证券目录联合资料与覆盖，允许仅资料、仅行情和完整状态，不扫描所有分片后在内存分页。

## 历史与复权

历史按最新分片向前有界读取，通过多读一条判断是否仍有更早数据。游标使用真实最早时间，保留小数秒；跨分片不能重复或遗漏边界记录。

none 返回原价，forward 以查询视图最新端因子为锚，backward 以最早端为锚。有界历史分页使用完整覆盖范围两端的固定锚，不能逐页定基。因子读取包含起点前最近生效值，缺失因子当前回退原价；改变此行为需同步 API 与存储测试。

复权只调整价格字段，没有明确市场规则时不变换成交量与成交额。存储日周线是交易日，盘中按交易所本地时间解释，在 API 边界加偏移；市场元数据统一定义，参考价属于查询结果而非证券静态资料。

## 同步质量

同步依次完成计划、外部读取、归一化、校验、写入和报告。日线批次校验标的日期、有限数值、OHLC 关系、非负数量和重复主键；非法批次整体拒绝，合法但覆盖不足仍保存已有行并记录定向重试。

写后只读主库 overview 核对覆盖，不逐证券回扫分片，也不在 API 轮询中重复质量扫描。成功写入才推进游标；重叠区供应商修订进入报告，合法新值仍可 upsert。

最近质量快照保存在 Alpha state/data-quality 中，保留有界明细和重试集合以及完整计数，重启可读，不混入可同步行情目录。

实时 MarketFeed 不持久化历史尾部、不参与 bars 或指标查询，租约与事件语义见 [事件运行时](event-runtime.md)。数据库维护入口是 `alpha/scripts/vacuum_sqlite_dbs.py`，没有独立 CLI 命令。
