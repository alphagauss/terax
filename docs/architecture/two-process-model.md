# Workspace 进程与共享状态

## 进程与环境

每个完整 Workspace 窗口拥有独立的 Rust 应用进程、WebView 和运行时资源。新窗口及环境切换启动新进程，不重置当前窗口。进程启动时选定的 Local、WSL 或 SSH 环境不可变；Space 仅保存分组、根目录和标签布局。

## Space 目录

Default 是固定 ID 的永久首项，不参与改名、排序和删除；允许移动工作页，初始目录解锁。其他 Space 默认锁定，保存项目根和自动命名状态，目录选择不创建终端。

- 锁定时，文件管理器、源码管理和 Agent 新草稿使用 Space 根；终端仍持续维护实际 cwd，文件打开和在指定目录新建终端不改变锁定根。没有工作页也可以显示锁定目录。
- 解锁时，文件管理器按本 Space 工作页及最近终端目录跟随，源码管理与新草稿使用相同有效目录；没有工作页则显示空态。跟随不修改持久化根或 Space 名称。
- 再次锁定将当前有效目录保存为根。新旧根不同时，自动命名的 Space 改为文件夹名；手工名称始终保留。主动选择目录同样保存根并锁定。
- 普通新建允许根为空，在首次获得工作页明确目录时绑定并自动命名，不把 Home 的展示回退当作项目选择。
- Default 中选择目录、浮层从文件夹新建和文件树“在新 Space 中打开”均创建并激活项目 Space；普通 Space 中选择目录则更新该 Space。Local 使用系统选择器，WSL 与 SSH 使用当前环境路径输入，校验并授权成功后才更新状态。
- 系统打开文件或文件夹统一交给 Local 主窗口，冷启动先恢复原有状态再处理请求。文件进入 Default；文件夹只复用已锁定且根目录相同的非 Default Space，优先当前活动项，否则取列表首个匹配项；没有匹配则新建锁定 Space，不创建终端。解锁 Space 不参与匹配，同目录和同名 Space 可以并存。
- WSL 与 SSH 路径输入支持 `/` 和 `~` 起始的一级文件夹补全；名称输入仅筛选当前层，选择只填入路径，追加 `/` 才读取下一层。粘贴路径读取其父目录进行补全。`~` 在读取和提交时展开为登录用户家目录，不使用 SSH profile 的项目根代替。
- 根目录与锁定状态独立于布局持久化，恢复时覆盖无工作页的目录授权和远端准备。失效目录保留原路径并显示失败，不能自动切到 Home。既有 Agent 会话和 Git 工作页仍使用各自绑定的目录或仓库。

## 窗口身份

每个环境有一个稳定身份的永久主窗口；其他窗口使用临时 UUID，不进入启动恢复列表。辅助窗口属于同一进程，不拥有另一套 Workspace，见 [辅助窗口](auxiliary-windows.md)。

WebView 通过原生接口访问文件、进程、Shell、网络和秘密。桌面注册入口为 `src-tauri/src/desktop.rs`，共享服务的桌面接入位于 `adapters/tauri/`。命令签名和权限以源码与 capability 为准，本文不维护命令目录。

## 共享与恢复

- 终端、LSP、SSH/SFTP、隧道及 AI 运行实例属于各自进程，不能跨窗口传递。
- 全局可写配置经 `shared_store.rs` 白名单入口，在 OS 锁内读取最新值、执行最小变更并原子替换。前端不得整表写回过时快照。
- 窗口内业务状态统一读写各自 Workspace 存储，不按主窗口或临时窗口身份跳过保存与恢复；临时状态是否保留由窗口生命周期统一管理。
- 窗口存活以 Workspace OS 锁为准，不增加心跳。激活、打开文件和工作页描述进入可丢弃的运行时交换文件，不进入共享设置或恢复状态。
- 页面移动、分割或隐藏保持稳定实例；SSH 资源压力下对隐藏空闲终端的显式回收例外见下文。标签顺序与激活状态只由 Workbench 管理。终端标签 `tab.id` 是前端会话、renderer pool 和 Agent 路由的唯一身份，原生 PTY ID 由会话层映射。
- 前端路径统一为正斜杠；系统输入在边界兼容两种分隔符，相同规范路径不得触发文件树重置。
- 文件变化由 Workspace 级监听入口统一分发，文档、目录树和 Git 各自读取权威状态。Local 与 WSL 仅监听前台资源，SSH 前台资源按三秒轮询，后台资源停止监听和轮询；资源激活、窗口恢复或远端重连时必须立即校验。
- 侧边栏与工作页统一按真实可见性管理展示读取。切走、隐藏或离开 Space 时释放展示订阅、停止轮询并清除待执行补查；不可取消的原生读取可完成，但不能启动隐藏视图的后续读取。快速切回复用同一资源的在途请求，陈旧结果不能更新其他资源或新连接。Agent、终端、传输、保存等业务运行时继续执行。
- 视图状态按 Space、有效目录和视图身份隔离，资源快照按环境、资源与查询参数复用。恢复先展示已有快照、展开项及阅读锚点，再由领域校验当前资源；由用户操作产生的结果只恢复，用户修改条件或明确重新执行才发起新请求，不因显示、恢复或重挂而重放。目录及 Git 校验失败保留已有成功内容。
- 展示缓存只保存在当前窗口内，按 LRU 淘汰并共同使用约 32 MiB 的非活跃数据预算；大小按展示数据估算，不代表整个窗口的堆内存上限。侧边栏保留最近九个 Space 目录上下文，活跃视图受保护；关闭 Space 或工作页释放专属状态。未保存内容、草稿和持续运行实例不属于可丢弃缓存，页面隐藏或移动仍保留原实例。
- 源码管理仅在侧栏可见或文件树可见且需要 Git 装饰时维护当前 Space 的共享 Git 状态；侧栏可见时三秒，仅文件树消费时五秒校验，没有可见消费者时停止。自动周期从本轮全部读取结束后开始，等待时间不短于本轮耗时；事件合并补查且轮间留出间隔。行数统计只在面板可见时读取，复用同轮状态，历史按引用变化及用户分页需要读取；SSH 在原生采集层合并固定命令批次，不改变公共解析和消费语义。
- 窗口可见但失去焦点时仍跟踪当前展示的资源，支持分屏工作；窗口隐藏或最小化时暂停监听与定时轮询，恢复显示后立即校验。窗口焦点变化不改变标签页和 Space 的前后台归属。
- 工作区内容搜索按需扫描，与 AI grep 共享匹配引擎，不增加索引、watcher 或持久搜索历史。
- LSP 按需启动，没有 root marker 不创建 session；未启用时不启动进程或做 PATH 探测。

工作页复制的可用类型、消费和失败语义见 [跨窗口复制](workspace-page-handoff.md)，会话锁与恢复见 [AI 子系统](ai-subsystem.md)。

### 工作页浮层

每个工作标签页拥有稳定的页内浮层宿主，与页面实例一起移动和隐藏。非模态浮窗允许继续操作页面，点击可置前；页内模态对话框只禁用本页底层内容和较低浮层，不遮挡标签栏、活动栏或其他分屏。多个模态对话框只有最上层可交互，Escape 交给当前浮层，关闭后归还焦点。页内模态不声明整个文档为模态，也不设置全局焦点锁或 body 滚动锁。

切换标签或 Space 保留打开状态、内容实例和未提交输入，隐藏期间禁用交互，回到所属分组后恢复模态焦点。显式关闭浮层会卸载其内容，关闭工作页释放整套浮层；本阶段不承诺关闭重开或应用重启后恢复。展示查询依据页面可见性暂停，业务任务仍由各自运行时管理。

页内模态遮罩沿用全局对话框的浅模糊效果，范围限制在所属工作页，不支持背景模糊时保留半透明遮罩。点击遮罩关闭由业务显式启用，默认关闭以保护编辑草稿；只有当前可交互层的遮罩响应，标签栏、活动栏及其他分屏点击不触发关闭。非模态持久浮窗不添加遮罩或外部点击关闭。

页内浮层需要显式使用 Workbench 的公共组件，已有全窗口对话框不会自动改变作用域。内部菜单等子浮层必须进入所属浮层容器，采用非全窗口模态行为并在页面隐藏时收起，不能默认 Portal 到 body。浮窗位置和尺寸由调用方控制，拖动、缩放与布局持久化按后续业务需求增加。

## SSH 边界

当前远端契约为 Linux 与 Bash。连接在原生启动阶段建立，前端以权威快照补足可能错过的事件；秘密不经命令行或 Workspace 文件传递。

SSH 传输断开后先执行 profile 指定次数的快速重连；网络故障超过该次数时保持断开状态和手动重连入口，并在当前进程内定期后台重试。显式重连会取消旧重试；凭据、主机密钥或配置等需要用户处理的错误停止后台重试。成功连接后建立新的 epoch，不恢复旧远端进程。

正文和单层目录读取使用 SFTP；文件版本、条件写入与递归树等可使用封闭 Bash 任务。文件内容统一经 `remote/file_service.rs`，通用任务执行仅对 `remote/tasks/` 内部开放，不能成为任意命令入口。批量传输使用任务独占 session。

同一 transport 的 session 统一准入和计数，额度在服务端确认关闭后归还；转发 channel 不计入此预算。初始预算是客户端保守值，不宣称已探测服务器上限。达到预算时至多一个请求试探额外额度，成功提高当前连接预算，资源类拒绝后停止扩容，先回收闲置资源再有界等待或重试；权限拒绝等错误直接返回，不重放已发出的业务命令。重连建立新的账本。

普通文件 SFTP 保留高延迟复用和流水线，空闲到期或资源紧张时回收，活跃请求不能被中途关闭；内部命令不维持空闲预热 channel。等待可取消且有截止时间。批量传输的调度与额度约束见 [文件传输](file-transfers.md)。

仍无法取得额度时，可以回收隐藏且明确空闲的 SSH 终端。必须有当前 Shell 的明确空闲和无后台作业状态，没有未提交输入、待发送输入、活跃 Agent 或交互程序；状态未知不回收。回收结束原 Shell，保留页面、输出和最近目录，并显示提示；再次显示页面才启动新 Shell，不恢复临时环境变量、函数等 Shell 内存状态。可见终端和运行中的任务不因资源压力被抢占。

编辑器外部刷新统一通过文件同步入口处理 Local、WSL 与 SSH，只保留最近一次完整校验的原始字节检查点，不建立远端缓存。SSH 在一次封闭任务中检查元数据并计算分块摘要，变化正文复用 SFTP 的合并区间流水线；能力缺失时沿用普通读取。检查点在字节组装和全文摘要校验成功后更新，文件截断、替换或传输中断不能推进失败的检查点。每轮 SSH 同步只处理本轮捕获的长度，之后追加的内容留给下一轮；同一文件串行同步并合并期间收到的检查请求。

同步检查点与编辑保存的冲突基线分别维护，外部变化仍按原有本地、基线、磁盘三方关系协调。外部刷新不进入撤销历史，并以最小文本变更保留阅读位置与可映射的手动编辑历史。

任务能力绑定当前连接 epoch，依赖缺失只关闭相关路径；重连丢弃旧能力，显式重检可以刷新结果。变更请求已经发出且结果不明确时必须收敛版本或报错，不能盲目回退并重复写入。安全规则见 [安全模型](security-model.md)。
