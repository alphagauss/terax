# Channels

Channels 为消息平台提供内置 Agent 入口。当前个人微信接受扫码账号本人的私聊文本、文件、图片、视频和语音，不提供群聊、远程审批、定时通知或流式回复。Local 永久主窗口的消息通道侧栏可主动发送文字和文件。

## 连接归属

- 仅 Local 永久主窗口启动 TS 连接服务；设置窗口和其他 Workspace 只消费状态。关闭侧栏不停止连接，主窗口退出则停止，不提供独立 daemon。
- 连接实例使用稳定 UUID。同一微信账号不能重复注册，重新扫码不能把既有实例改绑其他账号。
- 实例独立接收、重连与执行，不设置跨连接执行锁；实例内入站准入串行，各对话独立执行；发送出口按连接串行。禁用实例不请求、不重连，队列有界并通过背压等待。
- busyMessageMode 为 steer 时接入同一对话的当前轮引导，为 queue 时等待本轮及回复后开启下一轮。运行关闭接入后的消息进入下一轮。

## 对话与会话归属

账号身份由平台类型与账号 ID 确定，与账号 cwd 使用同一身份来源；对话类型、对话 ID 与可选话题 ID 规范化后，与账号身份共同生成确定性 UUID v5，作为 session ID。实例 UUID、名称和绝对目录路径不参与会话身份。通过适配器准入检查的首次来信登记可读对话索引，先保存索引再推进协议检查点与执行；重启、同账号重新授权及移除后重新添加实例均复用会话 ID。不同用户的私聊、不同群组和不同话题隔离历史、模型上下文、运行状态、输入队列与取消；同一群组或话题内不同成员共享会话，模型输入标明发送者。使用 Channel 智能体、按连接配置的模型和完全访问权限，不修改桌面聊天选择与草稿。

cwd 属于平台账号，位于 `~/.terax/channels/<平台类型>-<账号短哈希>/`。目录键由平台类型和账号 ID 共同导出，不暴露原始账号；短哈希仅使用 Base64URL 文件名安全字符。连接 UUID、昵称和扫码产生的平台连接资源 ID 不参与目录身份。删除连接保留账号工作目录与账号对话索引；重新添加同一账号复用目录、索引和会话历史。同一账号下的对话共用此目录；会话隔离不是文件系统沙箱。

附件平铺保存于 cwd 内的 `attachments/`，保留平台提供的原名，仅处理非法路径字符。重名在扩展名前追加 `(1)`、`(2)` 等序号，通过原子发布保证并发接收不覆盖；会话记录实际保存路径。平台没有提供原名时，按媒体类别使用默认名称。附件身份独立于文件路径，不再创建 UUID 子目录。模型看到名称、媒体类别、下载状态和 cwd 相对路径；成功物化的图片还以通用视觉文件输入随该消息传入模型。文件工具与 Shell 沿用原有 cwd 解析，不引入虚拟路径或强制输出目录。凭据和协议检查点不放进账号 cwd。

模型引用与按模型保存的参数覆盖复用 AI 模型使用配置，按连接 ID 隔离；未指定模型时使用全局默认模型及当前连接对它的参数覆盖。新一轮 Agent 任务开始时冻结实际模型和参数，整个工具循环与当前轮引导保持快照；是否排队不决定配置读取时机。模型配置修改不重建连接或会话，不影响正在运行的任务。

metadata 的 channelId 保存不可变的账号 UUID，只有匹配账号在 Local 永久窗口可以提交，历史中也禁止人工续写。该账号仍有配置的连接时不能普通删除会话；移除连接保留历史，之后可按普通历史删除流程清理。

Agent 本轮 JSONL 终态保存并释放锁后才回复，只取最后一步可见 Assistant 文本。推理、工具和内部事件不投递。中止只清空该对话的未消费输入，不发送该轮最终回复；已接受消息身份保留。

命令遵循 [会话命令](ai-subsystem.md#会话命令)。即时命令在当前任务期间独立保存并回复原消息，复用有序投递出口，但不计入 Agent 工具发送的回执或合并回复身份；其余命令沿用对话队列。附件准备或会话保存失败只暂停该对话，不停止其他对话的接收与执行；投递失败不重跑命令。

## 消息与投递边界

TS 平台注册表拥有适配器创建、登录和凭据清理入口；连接运行时负责去重、顺序、背压与取消；账号目录命名和附件路径也由 TS 决定。微信上传协商、地址白名单、密钥编码、媒体类型和消息字段只在 TS 适配器中解释。Rust 不读取 Channel 配置、不认识微信接口，只提供既有文件权限与 HTTP 边界上的通用快照、字节变换、上传和下载能力；传输字节不经 WebView 往返，只有已保存且准备作为模型视觉输入的图片会经既有受限本地读取转换为 Data URL。通用传输的生命周期见 [网络规则](network.md)。

一条平台消息直接形成一条 Agent 输入。先记录身份，再准备附件与通用视觉媒体，随后接入既有 steer / queue；下载失败保留附件事实而不提供虚假的可读路径。消息中的多张图片形成多个视觉文件输入，并由一段汇总文字说明其路径；非图片附件逐条提供路径说明，不做跨消息等待、自动组装或定时处理。纯附件也是有效输入，但收到文件本身不代表要求解析；Agent 根据上文决定是否处理，没有明确要求时简短确认，等待后续消息。微信提供的语音转写作为用户文字输入，原音频独立保存；本地自动转写和媒体转码不属于此链路。

图片 MIME 优先按实际文件签名识别，再回退到扩展名。Provider 在请求建立时明确拒绝视觉输入，统一模型调用层将图片替换为文字占位并仅重试一次；成功建立降级请求后，仅当前运行的模型实例沿用降级，原始会话图片保留。桌面、Channel 和 Subagent 共用此边界；不根据模型名称预判能力，不在流建立后重试或重放工具。

`message` 仅向当前 Channel 主运行提供，Subagent 和普通桌面会话不能使用。目标在运行开始时绑定，模型只提供文字、文件路径及展示形式。相对路径按账号 cwd 解析，绝对路径沿用完全访问的原生文件边界；不从 Assistant 文本自动提取路径发送。文件默认以文件形式投递，图片、视频和语音形式由调用显式指定，平台不支持时明确失败，不隐式改变发送形式。

人工发送、命令回执、工具发送与最终回复共用按连接实例串行的投递出口；出口不等待 Agent 结束才消费，避免工具等待发送回执时互相阻塞。回执区分平台接受、部分成功、失败和不确定结果，并保留逐项状态；平台接受不代表用户已读。工具结果进入既有会话记录，工具发送可早于整轮终态保存，取消不能撤回已发送内容。工具已成功投递且没有最终文字时，不补发空回复兜底；普通最终文字仍独立发送。

单附件原生大小上限为 32 MiB，传输和读取有界，重试不会重新执行 Agent。上传时取得内容快照，随后发送平台资源引用。账号目录中的材料和产物随目录保留，不随连接移除自动删除。

## 应用发送与通用契约

连接实例、对话目标、发送者和应用会话是独立身份。入站与出站共用对话目标，包含私聊或群组地址及可选话题；平台 ID 使用不透明字符串。应用根据已接纳的来信发现对话；平台权限仍由各适配器负责，当前微信继续只接受本人私聊。不得把同一实例不同目标的消息引导进当前轮，或把最近收件目标当作通用发送默认值。

适配器拥有平台解析、协议上下文、附件传输、文本拆分和逐项平台回执；公共运行时拥有去重、队列、取消与实例生命周期。命令分流、Agent 接入和会话持久化属于应用业务，不下沉到适配器。面板选择实例下已发现的会话，应用接口校验会话属于该实例，再解析其固定目标；连接在线且目标属于已发现会话时即可提交发送；适配器校验平台目标与解释发送结果，不向公共层暴露上下文门槛。底层发送请求明确携带实例、目标与内容，不要求提供一条入站消息，也不依赖 Agent 正在运行。

人工发送复用所选对话的会话 JSONL：先保存发送请求再投递，随后追加结果。正文直接展示，附件只展示本地路径；这些记录不形成 SDK 消息、不进入模型上下文。保存失败只补写记录，不重跑投递；没有结果的历史显示未确认，重启不自动重发。没有对话时提示先在通讯软件中发起私聊或群内消息。停用或重启后保留对话列表与历史预览，缺少发送上下文不隐藏历史。消息通道与 AI 面板按会话 ID 订阅同一 Chat、命令与投递展示记录，新增、编辑、删除和通知处理即时同步，不另行读取并缓存历史副本。冷历史按需加载，隐藏只释放展示引用，多个页面共用实例且不重启业务运行。外部会话变更复用既有文件指纹刷新，使消息、命令和投递缓存一起失效；删除或读取失败时不保留旧展示，较早的异步读取不能覆盖新选择或新版本。自动回复按稳定消息 ID 归属，原消息移除后不再显示其回复记录，人工发送与显式重发仍独立保留。当前面板展示接收、命令、Agent 正文与人工发送历史，草稿按对话隔离；隐藏或切换面板不停止发送。输入的斜杠文本按原文发送，不在桌面发送面板解释为命令。

模型运行失败复用 AI 会话保存的失败事件及实际原因，向通讯平台发送系统通知；通知的投递结果附在失败事件下，不再作为独立 Agent 回复。投递与忽略状态仍不进入模型上下文。

Agent 回复、命令回复和工具发送复用相同的投递记录，保存来源、逐项结果及不含凭据的通用原因，不进入模型上下文。适配器负责解释平台响应；微信成功请求不要求额外确认字段，成功空响应也视为已发送。在线状态与本次运行的投递异常独立展示，后续成功发送清除该对话的投递提示。消息卡片保留历史结果与原因，重启后按需读取。当前会话汇总未处理的发送结果通知，可定位消息、忽略单条或忽略全部。忽略只更新通知为已忽略，不改写发送事实；重新发送保存新请求并关联旧记录，旧通知变为已重新发送，新结果归属新卡片，不重跑 Agent 或命令。忽略全部只处理点击时指定的记录；发送中的记录不能忽略或重试，新请求保存失败保留旧问题。通知与发送记录共用会话 JSONL，重启恢复处理状态，不扫描全部历史生成长期告警，也不自动重发。

当前微信按附件顺序逐项发送，再完整分段发送文字，一次提交可能对应多条平台消息。单次人工提交最多 16 个文件、32000 个文字代码单元；不自动截断正文或重发部分成功的请求。平台接受不表示对端已读。文件默认按文件形式发送，媒体展示形式仍由底层通用接口表达。

## 持久化与失败

连接配置位于 `~/.terax/channels/config.json`，继续使用共享配置锁。检查点位于 `~/.terax/channels/state/<connectionId>.json`，由 Local 永久主窗口独占，通过普通文件接口原子保存完整 JSON，不进入 shared_store，不创建逐文件 `.lock`。账号级可读对话索引位于 `~/.terax/channels/state/<平台类型>-<账号短哈希>.conversations.json`，不进入 Agent cwd，也不读取 cwd 中旧的 `conversations.json`。连接与账号索引的写入由运行时串行，停止并等待接收、执行和写入结束后才能删除连接检查点；缺失文件与读取失败明确区分。模型使用配置位于共享设置 `~/.terax/shared/terax-settings.json`，正文仍在会话 JSONL，凭据走秘密存储。索引只记录目标与 session ID，展示名称由目标派生；索引丢失后仍可从账号与目标计算原 session ID。索引先保存，再推进实例检查点，移除实例保留账号索引；待处理正文和回复上下文只存内存，不进入检查点。

- 消息去重身份包含对话目标，避免不同群组复用平台消息 ID 时误去重；身份先保存再排队，批次接收后才推进游标。游标绑定平台连接资源，凭据资源变化时重置游标并保留去重身份及会话。
- 检查点保存失败停止该连接的接收与执行，不阻塞其他连接。
- 异常退出或停止后的未完成请求不自动重放，用户需要重新发送；不承诺 exactly-once 副作用。
- 多片段或多附件投递中途失败时停止后续项，已成功项不重发。发送请求响应丢失或无法解释时记为不确定结果，不自动重试，也不重跑 Agent。
- 会话保存失败由运行时保留正文与锁；修复后先补交终态再执行下一轮。
- 移除连接先清理协议状态、路由和该连接的模型使用配置，再删连接配置；失败保留实例供重试。正文锁文件保留，避免破坏跨进程锁身份。

## 微信与设置

扫码和协议重定向只接受白名单微信域名的 HTTPS origin，拒绝任意端口、userinfo 与跨站地址；HTTP 自动重定向拒绝。确认前不替换有效凭据，验证码查询失败保留输入。回复固定使用原消息的对话目标，适配器复用已有长轮询获取最新协议上下文，不增加刷新请求或定时器。上下文只留在服务内存，不写展示历史；有上下文则携带，没有也允许向已有会话发送，由微信返回实际结果。

设置通过定向消息管理唯一服务。名称、消息策略和网络路由显式保存，独立模型配置区即时保存，切换实例或状态刷新不覆盖草稿；启停与授权即时执行，切换设置页不取消扫码。名称变化不重建接收任务或改写历史标题。配置与网络属于不同存储，部分保存失败保留草稿并仅重试差异。

HTTP 传输和出口选择复用 [网络规则](network.md)，Agent 接入复用 [会话运行时](ai-subsystem.md)。协议实现入口为 `src/modules/channels/adapters/weixin.ts`，本文不复制远端字段与内部模块清单。
