# Channels

Channels 为消息平台提供内置 Agent 入口。当前个人微信只接受扫码账号本人的私聊文本，不提供群聊、媒体、远程审批、主动定时消息或流式回复。

## 连接归属

- 仅 Local 永久主窗口启动 TS 连接服务；设置窗口和其他 Workspace 只消费状态。关闭侧栏不停止连接，主窗口退出则停止，不提供独立 daemon。
- 连接实例使用稳定 UUID。同一微信账号不能重复注册，重新扫码不能把既有实例改绑其他账号。
- 实例独立接收、重连与执行，不设置跨连接执行锁；同一连接保持顺序。禁用实例不请求、不重连，队列有界并通过背压等待。
- busyMessageMode 为 steer 时接入当前轮引导，为 queue 时等待本轮及回复后开启下一轮。运行关闭接入后的消息进入下一轮。

## 固定会话

每个连接绑定固定 session UUID，重启和同账号重新授权不更换。使用 Local 默认 Agent 目录、Channel 智能体、每轮冻结的全局默认模型和完全访问权限，不修改桌面聊天选择与草稿。

metadata 的 channelId 不可变，只有匹配连接在 Local 永久窗口可以提交，历史中也禁止人工续写。仍绑定连接时不能普通删除会话；移除连接保留历史，之后可按普通历史删除流程清理。

本轮 JSONL 终态保存并释放锁后才回复，只取最后一步可见 Assistant 文本。推理、工具和内部事件不投递。中止清空未消费输入，不发送该轮最终回复；已接受消息身份保留。

## 持久化与失败

配置与有界协议状态位于 `~/.terax/channels`，正文仍在会话 JSONL，凭据走秘密存储。待处理正文和回复上下文只存内存，不进入检查点。

- 消息身份先保存再排队，批次接收后才推进游标。游标绑定平台连接资源，凭据资源变化时重置游标并保留去重身份及会话。
- 检查点保存失败停止该连接的接收与执行，不阻塞其他连接。
- 异常退出或停止后的未完成请求不自动重放，用户需要重新发送；不承诺 exactly-once 副作用。
- 投递失败只重试当前文本片段并保留客户端消息 ID，不重跑 Agent。平台已接收但响应丢失仍是不确定结果。
- 会话保存失败由运行时保留正文与锁；修复后先补交终态再执行下一轮。
- 移除连接先清理协议状态和路由，再删配置；失败保留实例供重试。正文锁文件保留，避免破坏跨进程锁身份。

## 微信与设置

扫码和协议重定向只接受白名单微信域名的 HTTPS origin，拒绝任意端口、userinfo 与跨站地址；HTTP 自动重定向拒绝。确认前不替换有效凭据，验证码查询失败保留输入。回复使用原消息对端和上下文，长任务发送前尝试刷新上下文。

设置通过定向消息管理唯一服务。名称、消息策略和网络路由显式保存，切换实例或状态刷新不覆盖草稿；启停与授权即时执行，切换设置页不取消扫码。名称变化不重建接收任务或改写历史标题。配置与网络属于不同存储，部分保存失败保留草稿并仅重试差异。

HTTP 传输和出口选择复用 [网络规则](network.md)，Agent 接入复用 [会话运行时](ai-subsystem.md)。协议实现入口为 `src/modules/channels/adapters/weixin.ts`，本文不复制远端字段与内部模块清单。
