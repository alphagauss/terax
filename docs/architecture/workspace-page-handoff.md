# Workspace 工作页跨窗口复制

主窗口可把白名单工作页复制到同环境临时窗口。新窗口预先获得临时 UUID，即使源主窗口退出也不能改用永久主窗口身份；关闭多窗口模式时入口和原生发送均拒绝。

## 可复制内容

已保存的 Editor、Markdown、Web Preview 和非隐私 Terminal 可以复制。Terminal 仅按 cwd、模式和标题启动新 Shell，不复制输出、进程或任务。

脏文档、隐私终端、AI Diff、Git 临时视图当前不支持。不复制 Space、Group、分割布局、活动状态和页面 ID，也不提供移动、回传或关闭时自动转移。

## 消费与失败

描述写入 `~/.terax/workspaces/terax-workspace-runtime.json`，目标初始化后原子取走并在当前活动 Group 重建页面。文件是可丢弃的登记表与一次性队列，损坏可重建；存活判断使用 OS 锁，不增加心跳。消息有过期时间，采用至多一次消费，没有确认或回滚协议。

新窗口先投递再启动，立即启动失败删除该消息。源页面始终保留，失败后用户可以重新复制。轻量同进程页面见 [辅助窗口](auxiliary-windows.md)。
