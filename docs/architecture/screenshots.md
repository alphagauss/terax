# 桌面截图

所有 Workspace 都可在快捷键设置的系统全局分组中修改截图按键和启用开关，并在常规设置中手动启动本进程的截图流水线。WSL 和 SSH 窗口截取的也是运行 Terax 的本机桌面，不是远端桌面。

截图快捷键与应用内快捷键共用录制交互：点击组合键后录制，按下组合键保存，Esc 取消，同一页面只允许一项录制。系统截图保存物理键编码，由原生层继续验证格式与处理注册冲突。

只有默认 Local 环境的永久主窗口进程注册全局快捷键；该进程退出后其他窗口不接管，但仍可手动截图。快捷键开关只控制系统注册，不限制手动截图。各窗口按字段精确写入已有共享设置，默认 Local 进程通过现有配置变更通知重新读取最新值并更新注册；未运行时下次启动应用最新设置。注册冲突不回滚共享偏好，在默认 Local 窗口的快捷键设置中显示错误。页面上的应用内快捷键重置不修改系统全局截图设置。

## 交互与生命周期

快捷键触发时采集鼠标所在屏幕，随后在同屏显示不透明冻结画面的独立截图窗口。首版允许在单块屏幕内选区，不支持跨屏连续选择。确认将标注合成图复制到系统图片剪贴板；另存为使用本机系统对话框。保存取消或导出失败保留选区与标注，成功才结束会话。Esc 和系统关闭操作取消截图，保存执行期间不能用关闭操作丢弃会话。

截图窗口属于专用覆盖层，允许在其他应用上方显示，不属于普通辅助窗口的层级或恢复策略。位置与尺寸完全由 Rust 选择的显示器确定。它不承载 Workspace 或 Agent 运行时，不随普通页面移动、隐藏而重建。

截图窗口统一按需创建，结束会话立即销毁并释放图片和编辑器，不预热、不保留空闲窗口。销毁可能同步触发原生事件，因此必须在释放运行时锁后执行，并在销毁期间拒绝本进程重复启动。销毁失败保留会话，允许再次取消或导出。旧会话回调不能取消或导出新会话。

当前只做进程内防重复触发，不增加跨进程截图锁。不同 Workspace 恰好同时启动交互截图时，覆盖窗口可能重叠。

## 采集与边界

Rust 使用 xcap 采集，将快速无损 PNG 通过一次性二进制响应交给 WebView。react-screenshots 负责选区和标注；最终 PNG 通过二进制请求交还原生验证、复制或保存。图片不经 Base64/JSON 数字数组传递，不为预览落盘。导出前检查 PNG 尺寸、来源尺寸及像素上界。标注与选区使用逻辑坐标，导出按实际源图比例恢复像素尺寸。

react-screenshots 使用 pnpm 补丁修复发布包样式入口、按源图比例导出、导出后重置时机和图片就绪通知，并接入公共悬停提示。升级依赖时必须复核这些行为；业务不修改注册表管理的 UI 组件。

Windows、macOS、Linux X11 使用相同业务流程，macOS 需要系统屏幕录制许可。Wayland 的任意覆盖层位置和全局快捷键不满足当前交互契约，本版明确报告不支持，不回退为截取其他屏幕。Linux 安装包与 CI 包含 xcap 所需系统依赖。

截图能力目前不暴露为内置 Agent 工具。未来指定窗口采集须单独定义桌面权限与目标失效语义，不能复用 cwd 文件读取授权，也不能把本机桌面描述为 WSL 或 SSH 的远端桌面。

## 性能记录

采集、编码和总就绪耗时仅写入 debug 日志，不保留历史列表或显示在设置页。总计时从触发开始，到图片加载后完成原生 show/focus 调用结束，不代表显示器实际呈现时刻。记录不包含屏幕图片、窗口标题或路径。

比较应使用同一正式构建、显示器、分辨率和缩放；首次系统授权单独记录。内存比较使用同一宿主及相关 WebView 进程的增量，窗口销毁不保证浏览器和 GPU 缓存立即全部归还系统。开发构建的数据不能直接代表发行版本。
