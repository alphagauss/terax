# 内置网络与代理

Terax 的内置 HTTP 请求统一经过 `src/lib/http.ts` 和 Rust `net.rs`。AI SDK 继续负责供应商协议和响应解析，每个 runtime adapter 都显式注入原生 fetch。SDK 需要下载远端附件时也使用原生传输。

## 路由与配置归属

共享代理位于“设置 > 常规 > 网络与代理”，不设置独立导航页；各个连接的路由仍在所属功能中选择。

网络配置统一存入 `~/.terax/shared/terax-settings.json`，以 `network.` 前缀区分网络字段。精确键变更经过锁和原子替换，不写环境变量、不维护整表副本。

| 键 | 内容 |
| --- | --- |
| `network.proxyUrl` | 共享代理 URL，可含用户名，不得含密码 |
| `network.provider:<instanceId>` | 对应 Provider 实例的 `direct` 或 `shared` |
| `network.channel:<connectionId>` | 对应 Channel 平台连接的出口 |
| `network.speech:openai`、`network.speech:groq` | 在线语音服务各自的出口 |
| `network.markdown` | Markdown 网络图片的出口 |

缺失路由键表示默认直连。选择直连时删除该键；删除 Provider 或 Channel 时同步移除它的路由。共享代理配置本身不会启用任何连接。

前端请求只传 `NetworkTarget`，不传代理地址和代理密码。Rust 在请求开始时读取对应路由并解析共享代理。连接身份稳定，因此地址、模型和名称变化不会改变路由归属，已创建的 SDK 客户端也能在后续请求中使用最新配置。

模型目录与推理使用同一个 Provider 实例身份。聊天、Subagent、编辑器补全和提交信息生成不另设代理开关。Channel 的扫码、轮询、配置查询和回复共用 Channel 身份；它调用模型时仍使用 Provider 的独立身份。语音配置是独立服务，不自动继承同名模型 Provider 的路由。

设置窗口按需订阅通用配置，只在网络字段变化时更新网络修订；修改主题等其他偏好不会使模型目录缓存失效。模型目录缓存把网络修订计入缓存身份，代理配置和密钥变化后不会沿用旧请求结果。

## 代理与安全

`network_proxy.rs` 负责代理 URL 校验、路由与秘密读取，HTTP 和 SSH 复用它的配置模型。支持 HTTP、HTTPS 与 SOCKS5；SOCKS5 的目标域名由代理解析。共享密码使用 `terax-network` service，并按规范代理地址与用户名的 SHA-256 标识绑定账户，只有原生传输读取它。切换代理地址不会把其他出口的密码发送给新代理；留空保留所选出口已有的密码，清除按钮作用于当前保存的出口。普通共享存储的单键和批量写入都验证地址，不能通过绕过设置页保存内嵌密码。

所有 HTTP 客户端明确关闭环境或系统自动代理。选择共享代理但未配置、格式错误、认证失败或无法连接时请求失败，不回退直连。没有 `system` 模式、环境变量回退或旧格式迁移。

代理路由与 `allowPrivateNetwork` 相互独立：前者决定出口，后者决定目标地址权限。模型服务器的私网许可不扩展到 SDK 下载的不可信附件。

协议、metadata 地址、目标 DNS 分类、请求头、重定向、超时、响应上限与 WebView 取消隔离仍由 `net.rs` 执行。直连将 DNS 固定到已验证地址；显式代理是用户信任的出口，代理端 DNS 与实际转发无法由本机 DNS 固定约束，不能宣称代理模式具有端到端 DNS pinning。启用代理不关闭本机目标校验。

## 设置生效与连接生命周期

每个 HTTP 请求启动时解析路由，在途流不随设置变化而重建。Channel 当前长轮询结束后的下一个请求使用最新设置，不因路由修改重跑 Agent 或重发消息。需要立即切换时使用已有重新连接操作。

SSH profile 的 `proxyMode` 为 `direct`、`shared` 或 `custom`，缺省为直连，不能根据是否存在代理地址推断路由。只有 `custom` 使用 SSH profile 的 `proxyUrl` 和服务器专属代理密码；`shared` 从原生共享配置读取地址与密码。默认新建和导入的服务器直连，服务器列表显示模式。配置修改在下一次连接时生效，包括每次自动重连尝试；重连只刷新代理字段，保持当前 Workspace 的主机、身份和工作目录不变，不主动断开现有 PTY、SFTP 或隧道。

已保存的服务器代理密码在每次建连时从密钥链读取，一次性密码只在相同代理身份的当前连接生命周期内保留，切换出口时丢弃。

SSH 出口只控制 Terax 到服务器的连接，不修改远端程序的环境代理。

## 固定直连与范围

本机 Whisper.cpp 固定回环地址、直连并拒绝 HTTP 重定向。Rust 到 Alpha 本机服务的探活与 API 转发固定直连。

终端命令、外部 CLI Agent、Git 子进程、网页预览、外部浏览器和 Alpha Python 对外数据源使用各自网络执行环境，不受此 HTTP 路由管理。

## 验证

- 在隔离子进程中注入失效环境代理，验证默认请求仍直连、显式代理接收请求、代理失效后不会访问直连目标。
- 使用真实 SDK 工厂与原生事件替身验证所有 adapter 的目录和推理身份一致，以及 SSE 任意字节分片后的文本和工具调用解析。
- 合并配置后，普通偏好修改保持模型目录缓存，只有网络字段和凭据变化使缓存失效。
- SSH 重连刷新代理配置，但保持 Workspace 身份并隔离一次性密码。
- 保留 HTTP 取消、重定向和响应大小、Channel 去重与发送重试等既有回归测试。
