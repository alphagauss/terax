# 内置网络与代理

内置 HTTP 经 `src/lib/http.ts` 与 Rust `net.rs`。所有网络 Provider SDK 注入原生 fetch；模型目录、推理与 SDK 附件下载共用传输，供应商协议仍由 SDK 处理。

## 配置与生效

- 网络偏好位于 `terax-settings.json` 的 `network.` 键，由原生层按稳定连接身份读取。前端只传连接身份，不传代理地址或秘密。
- 默认直连，不继承环境或系统代理。共享代理配置本身不启用任何连接；Provider、Channel、语音和 Markdown 图片各自选择出口。
- 模型目录与推理使用同一 Provider 实例身份，聊天、Subagent、补全和 Git 提交生成不另设路由。Channel 调用模型时仍使用 Provider 出口。
- HTTP 在请求开始时读取最新配置，在途请求不重建。网络或凭据变化使模型目录缓存失效，普通偏好变化不影响它。
- 代理支持 HTTP、HTTPS、SOCKS5。普通配置不能保存内嵌密码；秘密按代理地址及用户名绑定，切换出口不沿用其他身份的密码。
- 显式代理缺失、认证失败或不可达时请求失败，不回退直连。

## 地址安全

出口选择与目标私网权限相互独立。模型服务器的私网许可不扩展到 SDK 下载的不可信附件。传输保留协议、metadata 地址、DNS 分类、重定向、头部、超时、响应上限与按 WebView 取消隔离。

直连固定到已验证 DNS 地址。代理是用户显式信任的出口，仍执行本机目标分类，但不能保证代理侧解析和转发具有端到端 DNS 固定。

## 文件传输

文件请求复用现有 HTTP 的地址、出口、请求头、重定向、大小和取消规则。TS 编排平台协议；Rust 只接收请求参数、文件上下文和明确的字节变换参数，不解释账号、平台令牌格式或业务响应字段。当前文件快照与落盘支持 Local，其他环境不隐式映射为本机路径。

上传先按照会话 cwd 与权限读取普通文件，形成不可变临时快照并返回原始大小、摘要和请求体大小；之后的上传使用该快照，不重新读取源路径。快照按 WebView 隔离，调用方在流程结束时释放，宿主销毁时回收，过期快照在后续访问时清理。在途请求持有自身引用，不因其他请求释放资源而改变字节内容。

下载仅在 HTTP 成功且字节变换完成后，按授权根内的相对路径原子发布新文件；拒绝覆盖、父路径逃逸和目录链接。调用方可选择重名时自动追加序号，返回值始终包含实际保存路径。失败响应不保存为目标文件。取消覆盖文件准备、网络传输与发布前等待，原生启动确认解决提前取消的竞争。

## SSH 与范围

SSH profile 显式选择直连、共享或专用代理。每次连接及自动重连读取最新代理字段，保持 Workspace 的主机、身份和工作目录不变，不主动断开现有 PTY、SFTP 或隧道。一次性代理秘密只在相同出口身份的当前连接生命周期有效。

SSH 代理只控制到服务器的连接，不改变远端程序环境。本机 Whisper.cpp 与 Rust 到 Alpha 服务固定直连。终端、外部 CLI Agent、Git 子进程、网页预览、外部浏览器和 Alpha Python 数据源使用自己的网络环境，不受本路由管理。
