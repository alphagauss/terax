# 辅助窗口

辅助窗口在当前应用进程中创建独立 WebView 和 React Root，用于设置、文件属性等简单业务页，不承载第二套 Workspace 或完整 Workbench。主窗口销毁时一并关闭。

桌面截图使用独立的覆盖窗口契约，见 [桌面截图](screenshots.md)。

- 原生注册表定义封闭页面类型、尺寸、能力和层级；前端不能提供任意 URL、label、权限或绝对屏幕坐标。
- 新窗口隐藏创建，原生定位、页面首次提交与外观同步后统一显示；首次显示不依赖隐藏 WebView 的动画帧，macOS 父子关系延迟到显示时建立。单例复用时仅显示并聚焦已就绪窗口，初始化期间只更新请求。原生保存带 revision 的请求快照，页面先监听再读快照，避免快速复用丢参数。
- Independent 允许与主窗口正常切换前后顺序；AboveWorkspace 只保持在所属主窗口上方，不对其他应用置顶。
- 不提供多实例、窗口位置尺寸恢复或动态能力修改。业务页面按需加载，未打开时不启动其连接和订阅。

设置使用 AboveWorkspace，复用白名单共享配置；Channels 管理权限仅授予设置窗口。文件属性也使用 AboveWorkspace，复用可见窗口时不重新移动；环境取当前进程，基础属性与可取消目录汇总分开加载，不跟随符号链接，保持只读。

新增页面在原生定义、前端懒加载注册表及精确 capability 中登记；请求参数、数据和关闭行为由业务模块拥有。完整工作页的新窗口使用 [跨进程复制](workspace-page-handoff.md)。
