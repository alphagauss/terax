# 通用辅助窗口

通用辅助窗口用于在当前 Terax 进程中按需显示简单业务页面。每个窗口拥有独立 WebView 和 React Root，但不承载完整 Workbench，也不拥有第二套 Workspace 运行时。

当前设置页和文件属性页接入该能力。完整工作页进入新窗口时使用 [Workspace 工作页跨窗口复制](./workspace-page-handoff.md)。

## 实现结构

- Rust `auxiliary_window` 模块是原生窗口定义的唯一来源。前端只发送封闭的 `open_auxiliary_window` 请求，不能指定 URL、label 或权限。
- 所有辅助窗口使用 `auxiliary-{kind}` label、`auxiliary.html` 和 `src/auxiliary/main.tsx` 公共入口。
- 公共入口按精确 label 懒加载已注册页面，并统一加载全局样式、主题、语言、错误边界和窗口布局。
- 新窗口始终隐藏创建，在 React 页面首次提交后显示。已存在的单例窗口只显示、聚焦并接收 `terax:auxiliary-open` 请求。
- 辅助窗口使用独立原生层级，不设置 parent、owner、transient 或 always-on-top。首次显示和复用时主动聚焦，之后由系统按用户点击正常切换主窗口和各辅助窗口的前后层级。
- 原生层按 label 保存带单调 revision 的最新打开请求。页面先监听事件再读取 `get_auxiliary_window_request` 快照，只接受更新 revision，避免首次挂载和快速复用之间丢失参数。
- macOS 使用原生窗口控制按钮；Windows 和 Linux 使用公共 `WindowControls`。前端从原生窗口读取最小化和最大化能力，不保存第二份配置。

## 窗口定义

注册页面可以静态声明：

- 初始尺寸和最小尺寸。
- 是否允许调整大小、最小化和最大化。
- 首次相对主窗口居中、相对显示器居中，或靠近主 WebView 内的来源点。

辅助窗口始终可以关闭，在逻辑和生命周期上从属于当前 Workspace，并以隐藏状态创建。主窗口销毁时原生层主动销毁全部辅助窗口，独立层级不能延长 Workspace 进程生命周期。来源点只是相对主 WebView 的定位提示，原生层负责 DPI 转换、工作区钳制和居中回退，前端不能指定绝对屏幕位置。当前不支持多实例、位置或尺寸恢复、动态修改原生能力、隐藏标题栏以及完全替换公共窗口 chrome。

页面可以向公共标题栏提供中间内容，并完全决定主体内容、数据来源、交互和业务状态。公共层不接受任意 React 节点作为窗口请求，也不定义通用业务状态协议。

## 设置窗口

设置窗口使用 label `auxiliary-settings`，配置如下：

- 单例，尺寸为 `900 × 700`，最小尺寸为 `820 × 620`。
- 允许调整大小，不允许最小化或最大化，只提供关闭操作。
- 每次创建时相对当前主窗口居中，不恢复上一次位置。
- 设置标签显示在公共标题栏中。首次标签通过已验证的 URL 参数传入，窗口复用时通过统一打开事件切换。
- 设置页继续通过白名单共享设置同步主题、语言和配置，不增加窗口专用存储。

## 文件属性窗口

文件属性窗口使用 label `auxiliary-file-properties`，配置如下：

- 单例，尺寸为 `520 × 620`，最小尺寸为 `440 × 480`。
- 允许调整大小，不允许最小化或最大化，只提供关闭操作。
- 首次创建时靠近 Explorer 右键来源点并限制在显示器工作区内；缺少有效来源点时回退主窗口居中。复用可见窗口时不重新移动。
- 打开请求只携带路径和可选来源点。文件系统环境始终取自当前进程不可变的 `WorkspaceProcessState`，辅助 WebView 不建立第二套 Workspace 状态。
- 基础属性与递归目录汇总分开加载。目录汇总可取消，不跟随符号链接；SSH 优先使用固定只读远端聚合 helper，helper 不可用时回退有界并发 SFTP 遍历。
- 首版保持只读，不执行 chmod、chown、ACL 修改、提权或递归权限变更。

Workspace 的 `window-state` 插件只跟踪 `main`。辅助窗口 capability 使用 `auxiliary-*` 基础权限，只开放公共标题栏和窗口生命周期所需 API；业务类型再按精确 label 增加所需的 Core 或插件权限。

## 新增页面

新增辅助页面时需要同时：

1. 扩展 Rust 打开请求枚举并提供静态窗口定义。
2. 在前端注册表中将固定 label 映射到懒加载页面。
3. 为该 label 增加最小 Tauri capability。
4. 由业务模块定义请求参数、数据同步和关闭后的业务行为；公共 revision 信封只保证最新请求交付，不解释业务字段。

未打开辅助窗口时不得加载业务页面，也不得建立额外连接、定时器或观察器。
