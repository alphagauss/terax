# PTY 与 Shell 集成

终端是长生命周期交互式 PTY。其前端身份和窗口归属见 [进程模型](two-process-model.md)，原生实现位于 `src-tauri/src/modules/pty/`。

## Shell 行为

- 初始化脚本只作用于 Terax 启动的 Shell，不修改用户配置；保留用户启动配置与 prompt 行为。
- OSC 7 表示 cwd，OSC 133 表示命令边界。Agent 状态通过 OSC 133/777 标记检测，不从普通 TUI 重绘文本猜测。
- Windows 按 PowerShell 7、Windows PowerShell、cmd 的顺序检测默认 Shell；cmd 不提供相同集成能力。
- 终端 Enter 发送 CR（`\r`）；LF 不能替代 Windows PowerShell 的输入约定。

## Blocks 命令与展示

Blocks 保留 Shell 原有提示符与原生命令回显，包括用户配置的用户名、主机名、路径和样式；提示符在上一条输出边界之后另起一行。独立输入栏不替代正文里的提示符。Blocks 保留提交原文，复制和再次运行不能使用回显或命令摘要。Shell 的 OSC 133 E 扩展以百分号编码报告完整命令；短 C 标记仍保留原生执行边界和 Agent 检测语义。没有完整命令来源时，不提供基于摘要的再次运行。

多行提交必须作为完整编辑内容交给 Shell。Unix Shell 仅在实际开启 bracketed paste 时使用该模式；PowerShell 集成通过 B 标记报告专用 PSReadLine 输入能力，接收编码内容后恢复全文并一次性提交。无法确认能力时保留输入并提示，不逐行执行或自动转换 Shell 语法。提交期间阻止重复发送，写入失败保留草稿。

命令块在命令首行右侧提供悬停操作入口，不缩窄正文；悬停和菜单操作期间允许短暂覆盖正文，避开滚动条。完整路径、耗时、退出状态及操作保留在浮窗菜单中，不常驻覆盖命令文字。最近命令入口复用同一菜单，供命令首行滚出视口或网格位置失效后使用；alternate-screen TUI 隐藏操作层。

分隔线使用 xterm 原生装饰层，操作入口沿用其 CSS 坐标，避免混用缩放后的 DOMRect。选择、复制和搜索共用 Shell 执行起止边界；结束时排除光标所在的空行，保留实际输出空行和无尾换行的末行，不通过裁剪空白文本猜测布局。无输出命令保持空范围，不能选入下一条提示符。读取时区分软换行和真实换行，搜索位置按终端单元格宽度计算；缩放后关闭旧搜索，避免继续使用过期行列位置。

已完成命令保存有总量上限的内存输出快照，超限淘汰整份旧快照，不静默截断复制内容；仍有可靠网格位置时可直接读取正文。Windows 本机与 WSL 经 ConPTY 传输，尺寸变化后的重绘可能使旧标记失配，因此撤销旧网格定位、选区及搜索，但保留已保存输出供最近命令菜单复制。缩放时正在执行的块不保存不完整快照，其余输出不拆成新块；新提交重新建立追踪，不依赖 Shell 重发提示符。提交后、执行边界到达前的尺寸变化不能封锁新命令。直接 Unix PTY 与 SSH 继续由 xterm 标记跟随重排，不使用 ConPTY 定位失效策略。

## 文件粘贴与拖放

只有本机终端接收宿主文件路径，WSL、SSH 终端拒绝文件粘贴和拖放，需通过文件管理器上传。文件路径优先于剪贴板附带的文本表示；多个路径按现有引用规则拼接，不附加回车，不执行命令。纯内存图片不生成临时文件，也不粘贴到终端；普通文本粘贴保持可用。

块终端处于命令编辑状态时，粘贴进入对应终端的命令编辑栏并保留编辑撤销；其他状态使用 xterm 粘贴。异步读取后按终端身份重新定位，不能因渲染器复用或输入栏切换而写入另一个终端。

## 生命周期限制

关闭应用、终端标签和 Space 共用关闭保护。Shell 命令状态从 PTY 原始输出跟踪，不依赖 renderer 挂载；嵌套 Shell 的提示符不能结束外层命令。Unix Shell 报告后台作业身份，关闭时在 local、WSL 或 SSH 的实际执行环境中重新核对存活状态，避免仅因 WSL 启动包装器或提示符辅助进程存活就判定有用户任务。

Windows 本机后台任务仍按实际 Shell 的原生 PID 核对子进程，排除控制台宿主；进程内线程作业不在该探测范围。本机缺少 Shell 集成时退回进程检测；WSL、SSH 缺少 Shell 身份或任一宿主查询失败时保留关闭确认，文案不承诺退出必然终止远端任务。用户已主动脱离 Shell 作业表的任务不属于 Unix 作业保护范围。

ConPTY 的创建与关闭必须串行化，重叠调用会使新终端无法输出。Windows PTY 必须由 Job Object 清理完整子进程树；仅终止直接 Shell 会遗留其开发服务器等后代。锁、缓冲和具体协议实现以源码注释及测试为准。

终端页面隐藏后仍接收 PTY 输出。运行中的 TUI 不能用旧快照加增量重绘恢复，详见 [renderer pool](terminal-renderer-pool.md)。`AiComposerProvider` 必须保持稳定挂载，不能因凭据加载条件改变而重挂载整棵应用树。
