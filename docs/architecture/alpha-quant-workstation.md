# Alpha 工作站

Alpha 是个人量化应用，以 Alpha 页面作为唯一入口，包含行情、自选、回测结果、数据管理和设置。自由画布工作台已移除；策略复盘和模拟交易页面尚未完成。后续方向统一见 [ROADMAP](../../ROADMAP.md)。

## Alpha 页面

Alpha 是独立的 Workbench 标签，内部完整包含左侧自选工具栏、可收起的自选区、行情、回测与数据管理切换区、辅助面板和右侧工具栏，点击活动栏 Alpha 图标打开或聚焦当前 Space 中的已有页面，并收起主侧边栏；重复点击不关闭页面。活动栏选中状态跟随当前聚焦页面。自动收起只发生在点击入口时，用户仍可手动展开主侧栏，离开 Alpha 不自动恢复。Alpha 入口仅位于主活动栏，可排序或隐藏，不移动到副侧栏。中央优先获得剩余宽度；窄窗口允许横向滚动，也可收起两侧。分隔线拖动只移动预览，松手后提交宽度；不逐帧缩放图表。

设置统一从 Alpha 页左侧工具栏底部打开页内模态对话框，不再提供独立设置标签。工具栏与设置不受业务服务可用性检查控制，首次未配置、停服和服务探测失败时仍可进入。设置修改的是共享配置与共享服务；切页保留数据目录草稿和解释器选择现场，隐藏时暂停状态轮询，已发起的服务操作继续完成。数据目录草稿不被后台快照覆盖，设置不响应遮罩关闭，提交或服务操作期间不允许主动关闭。

页面复用公共行情与回测场景、基础控件、查询缓存和业务 API。主标的、图表配置、视图与分区偏好在窗口间共享。待保存的展示修改即时反馈并覆盖读取快照，写入失败后恢复权威配置。页面恢复只保存页面类型，展示偏好仍由 Alpha 共享存储持有。切换或收起保留已挂载场景，隐藏场景停止展示查询和订阅，不取消后台任务。

自选业务由 Python 持有，[分组与命令语义](../../alpha/docs/api-contracts.md#自选)由后端统一定义，不把证券列表或行情副本存入布局。选择自选更新 Alpha 主标的，不改动历史回测结果。右侧目前提供证券资料和任务观察；任务面板每次打开、重连及收到合并后的事件通知时重新读取权威快照，不以事件记录代替任务列表，也不保存运行历史。

任务观察可额外打开页内非模态浮窗，图表的对比标的管理与指标编辑使用页内模态对话框。设置中的解释器选择同样使用页内模态；系统文件和目录选择继续使用原生选择器。浮层生命周期与隔离规则遵循 [工作页浮层](two-process-model.md#工作页浮层)。

对比标的配置即时生效，允许点击本页遮罩关闭；指标编辑保留未提交草稿，遮罩不触发关闭，使用明确的保存、取消或关闭操作结束编辑。

## 自选表

自选区由左侧工具栏展开或收起；分组栏的搜索入口打开可拖动的页内浮窗，搜索与添加不替换自选列表，添加目标为当前分组。

默认展示名称与完整代码、近二十交易日日线收盘走势、涨幅与最近收盘价。涨幅和收盘价共用双行单元格，只有涨幅参与排序；扩展的普通列单行显示。名称列限制宽度，剩余空间优先交给走势；窄侧栏保留走势并允许横向滚动。行情日期列可从管理菜单开启，价格提示始终注明所属日期与日线口径，不表示实时行情。

排序覆盖当前组全部成员，包括置顶项；缺失值始终末尾，同值保留普通手动顺序。临时排序仅存在于页面会话，各分组独立记忆；取消后恢复置顶与手动顺序，不影响其他窗口。排序期间禁用拖动和首尾调整，右键菜单打开期间固定行位置。

多选模式向右让出复选框位置，仅允许逐项、范围、全组勾选和批量移除、复制、移动。暂停分组切换、搜索、单项右键、主图切换、排序和重排；行情数值可以更新，行位置固定。批量操作即时提交，成功清空勾选但不退出模式；完成与取消多选只退出，不撤销已提交操作。列表虚拟化不改变全选和排序范围。

## 公共图表与场景

Terax Workbench 管理页面标签和分割。公共金融图表使用唯一 Lightweight Charts 引擎，统计分析使用 ECharts，不提前建设第二图表引擎适配层。

Controller 与公共图表负责实例、渲染与命令，不查询业务数据；Scene 连接行情、指标及具体业务状态；页面组合场景与展示偏好，不拥有后台任务。页面创建自己的图表实例，不搬运 DOM 或 Canvas。切换、分割和隐藏保持已挂载实例，关闭页面才销毁。

## 标的与行情

- 完整数据键包含证券、周期和复权，迟到响应及旧订阅不能写入新图表。
- 交易日与盘中绝对时间明确区分，时区、价格精度、成交量单位和涨跌色来自权威市场元数据，不能从浏览器环境或当前样本猜测。
- 历史仅消费服务端排他游标，回填去重并补偿 viewport；实时同时间替换、更晚追加。新数据与历史回填不重置用户缩放、滚动；用户离开尾部后只在主动“回到最新”时恢复跟随。
- 页面隐藏保留实例但暂停非必要工作；未启用实时、指标或对比时不建立相应查询、订阅或计算。

HTTP 历史与事件恢复的权威边界见 [后端协议](../../alpha/docs/api-contracts.md)。数据管理视图保持紧凑的日线前复权预览，完整周期与实时能力由 Alpha 行情图表提供。

## 指标、对比与导出

指标 definition 和计算来自 Alpha，前端只提交数据键、显示区间与参数，不上传原始 bars 或复制公式。颜色和 pane 比例只影响展示，不进入计算身份。每个指标实例保持稳定身份与独立配置，隐藏和重排不重建主图。

对比只提供相对收益模式，共用左侧百分比轴，右侧绝对价格轴保持不变。使用所有有效序列首时间的最大值作为共同起点，不填补缺失交易日；单标的失败或局部覆盖不阻塞其他图表内容，十字线缺少精确点显示空值。

Alpha 行情图表可导出当前主题 PNG 和 CSV，数据管理视图不显示导出入口。可访问性摘要与数据表提供非 Canvas 阅读方式；TradingView 来源声明保留在设置页与第三方声明。

## 模拟交易的已定边界

后续模拟盘使用独立虚拟账户、订单、成交和持仓模型，始终明确显示模拟环境。Alpha 拥有订单权威状态、参数校验与模拟风控；命令幂等，超时或未知结果不能重复下单，UI 不能用乐观状态伪造成交。

行情、账户、订单分别表达新鲜度，恢复先取快照再接增量。撮合、手续费、滑点和成交价格规则必须显式且可复现，布局配置不能修改账户或绕过风控。真实交易留到后续单独设计。
