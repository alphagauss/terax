# Alpha 工作站

Alpha 是个人量化工作站，当前提供数据、回测、自由画布工作台、三栏工作页和设置。两套工作布局均为实验，暂不决定替代关系；策略复盘和模拟交易页面尚未完成。后续方向统一见 [ROADMAP](../../ROADMAP.md)。

## 三栏实验页

三栏页是独立的 Workbench 标签，内部完整包含可收起的自选区、行情与回测切换区、辅助面板和右侧工具栏，不修改宿主主副侧栏。中央优先获得剩余宽度；窄窗口允许横向滚动，也可收起两侧。分隔线拖动只移动预览，松手后提交宽度；不逐帧缩放图表。

两套布局共用行情与回测场景、基础控件、查询缓存和业务 API，各自拥有展示实例。三栏主标的、图表配置、视图与分区偏好独立于自由画布保存，同类三栏页在窗口间共享偏好。待保存的展示修改即时反馈并覆盖读取快照，写入失败后恢复权威配置。页面恢复只保存页面类型，展示偏好仍由 Alpha 共享存储持有。切换或收起保留已挂载场景，隐藏场景停止展示查询和订阅，不取消后台任务。

自选由 Python 业务存储持有，首版提供单列表、证券搜索和幂等单项增删，不把证券列表或行情副本存入布局。选择自选更新三栏页主标的，不改动自由画布主标的或历史回测结果。右侧目前提供证券资料和任务观察；任务面板每次打开、重连及收到合并后的事件通知时重新读取权威快照，不以事件记录代替任务列表，也不保存运行历史。

## 自由画布与公共复用

Terax Workbench 管理页面标签和分割；Alpha 工作台内部使用自由画布，允许重叠，不自动压紧或碰撞重排。横纵吸附步长均为 15px，面板间距和工作台外边距均为 1px；折叠标题栏占两行，高 29px。

画布按视口和最右侧面板边界扩展，不设固定列数上限；列数和像素宽度同时调整，保持单格大小不变。拖动或缩放接近右边界时临时预留空间，结束后按实际内容收敛。主副侧边栏开关、窗口缩放和分屏不修改面板在画布中的坐标、尺寸或持久化布局；大屏新增空间可继续摆放，小屏滚动查看超出的面板。保留原滚动位置，超出可滚动范围时由浏览器限制。布局锁定只禁止移动与缩放，不影响标的绑定、折叠或置顶。

面板收起后只显示标题栏，保留位置、宽度和展开高度；展开恢复原高度并置顶，其他面板始终不动。收起期间允许拖动但不缩放，保留实例并暂停非必要展示工作。折叠动画使用固定内容尺寸的裁剪揭示，不逐帧改变图表尺寸。

点击或键盘聚焦面板时置顶，层级按布局网格数组顺序持久化，独立于面板菜单的稳定顺序。顶部面板菜单列出所有面板，以类型、标的和重复项序号区分；选择后只置顶并将标题栏定位到视口内，不改变坐标、尺寸或折叠状态。删除面板留下空位，不自动整理其他面板。

公共金融图表使用唯一 Lightweight Charts 引擎，统计分析使用 ECharts，不提前建设第二图表引擎适配层。复用边界为：

| 层级 | 职责 |
| --- | --- |
| Controller 与公共图表 | 实例、渲染与命令，不查询业务数据 |
| Scene | 连接行情、指标及具体业务状态，可被页面和面板共同使用 |
| Panel | 补充工作台标的绑定、可见性与配置 |
| Grid 与控制栏 | 摆放和面板操作，不拥有行情或交易状态 |

普通页面直接复用 Scene，不为复用内容引入完整网格。各页面创建自己的图表实例，不搬运 DOM 或 Canvas。面板移动、缩放、重排和隐藏保持实例，删除才销毁；单面板加载失败不影响其他面板。

面板实例与几何布局分离，descriptor 是可用类型、配置校验和加载入口的来源。模板实例化产生新 ID；拖动期间只更新视觉，结束才提交状态。主标的、锁定、同步开关、布局与面板配置使用同一共享 workstation 状态，不依附 Space 或单一窗口。

## 标的、联动与行情

- 仅提供主标的 follow 与单面板 pinned；恢复 follow 立即采用当前主标的。
- 时间范围和十字线同步独立开关，不随标的联动隐式启用；仅在当前工作台传播运行时事件，不持久化范围或十字线位置。
- 同步按周期与复权过滤。范围使用实际行情时间，十字线仅匹配接收方精确同时间 bar，不跳到最近点，避免回传循环。
- 完整数据键包含证券、周期和复权，迟到响应及旧订阅不能写入新图表。
- 交易日与盘中绝对时间明确区分，时区、价格精度、成交量单位和涨跌色来自权威市场元数据，不能从浏览器环境或当前样本猜测。
- 历史仅消费服务端排他游标，回填去重并补偿 viewport；实时同时间替换、更晚追加。新数据与历史回填不重置用户缩放、滚动；用户离开尾部后只在主动“回到最新”时恢复跟随。
- 页面隐藏保留实例但暂停非必要工作；未启用实时、指标、对比或同步时不建立相应查询、订阅或计算。

HTTP 历史与事件恢复的权威边界见 [后端协议](../../alpha/docs/api-contracts.md)。数据页保持紧凑的日线前复权预览，完整周期与实时能力由工作台图表面板提供。

## 指标、对比与导出

指标 definition 和计算来自 Alpha，前端只提交数据键、显示区间与参数，不上传原始 bars 或复制公式。颜色和 pane 比例只影响展示，不进入计算身份。每个指标实例保持稳定身份与独立配置，隐藏和重排不重建主图。

对比只提供相对收益模式，共用左侧百分比轴，右侧绝对价格轴保持不变。使用所有有效序列首时间的最大值作为共同起点，不填补缺失交易日；单标的失败或局部覆盖不阻塞其他图表内容，十字线缺少精确点显示空值。

工作台图表可导出当前主题 PNG 和 CSV，数据页不显示导出入口。可访问性摘要与数据表提供非 Canvas 阅读方式；TradingView 来源声明保留在设置页与第三方声明。

## 模拟交易的已定边界

后续模拟盘使用独立虚拟账户、订单、成交和持仓模型，始终明确显示模拟环境。Alpha 拥有订单权威状态、参数校验与模拟风控；命令幂等，超时或未知结果不能重复下单，UI 不能用乐观状态伪造成交。

行情、账户、订单分别表达新鲜度，恢复先取快照再接增量。撮合、手续费、滑点和成交价格规则必须显式且可复现，布局配置不能修改账户或绕过风控。真实交易留到后续单独设计。
