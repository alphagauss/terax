## 当前任务方案

本节是覆盖式临时记录；下一项任务开始时替换目标、范围、实施步骤和验证标准。

### 实施边界

1. 迁移公共 Button、Input、Textarea、Select 和对话框入口，删除 Alpha 调用方的默认字号、圆角与尺寸覆盖。
2. 设置页使用公共 PageHeader、SettingGroup 和 SettingRow；数据与回测页保留宽内容布局，区块标题与卡片采用统一密度。
3. 工作台保留稳定面板所有权、图表尺寸与领域交互，不增加密度状态、表单引擎或动画依赖。
4. 本次不改变 Rust 代理、Python 服务、事件协议、查询及持久化语义，因此不调整 Python 内部文档。

### 验证标准

- 完整前端类型检查、lint、测试和生产构建。
- 在真实 Tauri WebView 检查设置、模型表单、对话框和 Alpha 数据页面的控件高度、字号与内容布局。
- 验证设置窄窗口中的导航可达性、原生平滑滚动、键盘定位与 reduced motion。
