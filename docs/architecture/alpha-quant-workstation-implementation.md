## 当前任务

目标是在不新增独立行情页的前提下，把 `MarketChartScene` 中固定的周期、复权和图表类型改为受控配置，并让工作台图表面板严格校验、保存和恢复这些配置。数据页继续以紧凑模式使用固定日线和前复权，同时保留图表类型选择。

- 查询键和图表 `dataKey` 必须完整包含标的、周期和复权。
- 支持周期来自现有证券详情接口，不根据前端枚举猜测证券能力。
- Chart Panel 配置使用严格 schema；旧 `{}` 配置归一化为默认日线、前复权和蜡烛图。
- 配置更新只替换目标 panel，不修改网格坐标、标的绑定或其他面板。
- 本任务不实现独立行情页、成交量显隐、pane 比例、证券价格元数据、导出、指标、同步、对比或实时行情。

完成标准：数据页和工作台图表面板继续复用同一个 `MarketChartScene` 和公共图表；工作台可以切换并恢复周期、复权和图表类型；配置切换不会重建 Lightweight Charts 实例；旧查询和迟到响应不会污染当前数据键。

## 当前任务方案

本节是覆盖式临时记录。每次开始新的 Alpha 任务前，必须先用新任务的目标、范围、实施步骤和验证标准完整替换本节，不保留已完成任务方案的历史副本。长期结论和已完成基线同步到长期架构，任务历史由 Git 保存。

详细设计和后续依赖见根目录 [`plan.md`](../../plan.md) 的“任务 1：受控公共图表配置”。本节只记录当前执行范围和实际验证结果。

### 目标与范围

- 在行情领域模型中统一周期和复权类型，在图表模型中定义受控配置和紧凑度。
- 复用现有 `/api/alpha/securities/{vt_symbol}`，为 Scene 提供权威支持周期，不修改 Python 协议。
- 数据页拥有本地图表类型状态，周期和复权保持固定；Chart Panel 从持久配置读取全部三项配置。
- 保持 `FinancialChartController` 只消费受控图表类型和 bars，不让它认识 Alpha API 或工作台配置。

### 实施步骤

1. 增加模型、证券详情查询、Chart Panel schema 和配置更新纯函数测试。
2. 把 `MarketChartScene`、`FinancialChartFrame` 改为受控配置，并接入周期和复权选择。
3. 从 `AlphaPanelPool` 向面板传递稳定配置更新回调，并由工作台共享状态执行按 ID 合并写入。
4. 更新数据页、工作台面板、中英文资源和相关组件测试。
5. 运行完整前端 lint、类型检查和测试；仅在真实尺寸或隐藏恢复行为无法静态确认时进入运行时调试。

### 验证标准

- 查询键同时包含 `vtSymbol`、`interval` 和 `adjust`，旧请求晚返回时不会覆盖新配置。
- 证券未声明的周期不会出现在选择器中；`tick` 永远不会成为 K 线周期。
- 旧 `{}` Chart Panel 配置恢复为默认值，无效配置只影响对应 panel。
- 更新一个 panel 配置不改变其他 panel、标的绑定或网格坐标。
- 数据页和 Chart Panel 均渲染同一个 `MarketChartScene`，配置变化不重建图表实例。
- 所有新增文案、title 和 aria-label 同步提供英文和简体中文。

### 执行结果

- 行情模型已统一 `MarketAdjust`，图表模型已增加受控周期、复权、图表类型和 compact/panel density；数据页继续固定日线与前复权，只在页面本地保存图表类型。
- `MarketChartScene` 已使用完整 `vtSymbol + interval + adjust` 查询键和 `dataKey`，工作台面板通过现有证券详情接口只展示权威声明的 K 线周期，排除 `tick` 和未知值；紧凑数据页不发起未使用的证券详情请求。
- Chart Panel 已使用严格版本内配置边界，旧 `{}` 自动补齐日线、前复权和蜡烛图；模板从创建时就携带完整默认配置，无效配置不会进入共享状态。
- `AlphaPanelPool` 已向每个稳定面板绑定按 ID 更新配置的回调，工作台写入前再次经过 descriptor 归一化；更新只替换目标 panel，保持网格、标的绑定和其他 panel 引用不变。
- `FinancialChartFrame` 已在 panel density 使用紧凑 Select 提供周期、复权和图表类型，在 compact density 保留现有图表类型按钮；全部新增控件、title、aria-label 和选项同步提供英文与简体中文。
- 新增和更新的测试覆盖证券详情 API、权威周期过滤、完整查询键、迟到响应、旧配置迁移、目标 panel 更新、Scene 薄包装和 Controller 单实例生命周期。完整 `pnpm test`、`pnpm check-types` 和 `pnpm lint` 已通过；lint 仅保留既有 warning 和 info。本任务不依赖真实尺寸或原生状态，因此未触发 Tauri 运行时调试。
