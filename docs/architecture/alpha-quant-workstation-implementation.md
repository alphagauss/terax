## 当前任务

目标是把已经存在但分散在长期架构各处的复用规则集中说明，并统一 `Scene`、`Panel`、`Panel Chrome` 和 `Panel Grid` 的中文称呼。

- `Scene` 统一称为“业务场景组件”，负责把公共内容连接到行情、回测或模拟交易数据。
- `Panel` 统一称为“工作台面板”，只是在业务场景组件外增加工作台需要的标的绑定、可见性和面板配置。
- `Panel Chrome` 统一称为“面板控制栏”，`Panel Grid` 统一称为“面板网格”。
- 明确普通页面可以直接复用业务场景组件，不需要采用 24 列面板网格。
- 本任务只修改架构文档，不修改代码、协议、目录或持久化结构。

完成标准：文档能够用统一中文术语说明“公共内容 → 业务场景组件 → 普通页面或工作台面板 → 面板网格”的关系，并明确共用实现不等于跨页面共用同一个运行中实例。
