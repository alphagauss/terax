## 当前任务

目标是让现有同步任务从内部实现变成数据页可操作、可观察和可恢复的完整业务能力。

- 通过 Alpha API 启动、查询和取消证券、指数成分与日线同步任务。
- 统一任务进度、结果、失败批次和质量问题的查询协议。
- 支持安全重试失败工作，并在数据页展示覆盖缺口、质量结果和恢复状态。
- 通过任务、API 和前端测试锁定并发启动、失败与恢复不变量。

完成标准：用户可以从数据页发起同步，观察真实进度与质量结果，在部分失败后重试且不会破坏已完成数据或重复运行同一任务。
