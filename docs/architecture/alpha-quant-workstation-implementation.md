## 当前任务

目标是在不新增独立行情页的前提下，为工作台 Chart Panel 提供 PNG 和 CSV 导出，并让所有公共 Canvas 图表具备有界、可聚焦的文本摘要与 OHLC 数据表。

- 把现有 revision 重置桥收敛为稳定 `FinancialChartHandle`，由同一命令句柄提供视图重置和不含十字线的截图。
- PNG 使用当前主题 surface 铺底；CSV 固定导出全部已加载 bars，最多 50,000 根，时间和空扩展字段保持领域语义。
- 工作台小面板通过紧凑菜单提供 PNG 和 CSV；数据页默认隐藏导出入口。
- 所有密度都保留 `aria-live` 摘要和最多 20 根 K 线的可聚焦数据表，不渲染完整历史。
- 本任务不修改 Alpha Python 或 Rust 协议，不实现独立行情页、指标、同步、对比或实时行情。

完成标准：导出不改变 viewport、十字线和 pane 比例；下载失败有本地化通知；键盘和屏幕阅读器用户可以读取当前摘要及有界表格；紧凑数据页不显示导出菜单。

## 当前任务方案

本节是覆盖式临时记录。每次开始新的 Alpha 任务前，必须先用新任务的目标、范围、实施步骤和验证标准完整替换本节，不保留已完成任务方案的历史副本。长期结论和已完成基线同步到长期架构，任务历史由 Git 保存。

详细设计和后续依赖见根目录 [`plan.md`](../../plan.md) 的“任务 3：图表导出与可访问性”。本节只记录当前执行范围和实际验证结果。

### 目标与范围

- 新增独立导出模块，集中处理安全文件名、CSV 转义、有界序列化、Canvas 主题铺底和 Blob 下载。
- Controller 只公开截图命令；React 宿主通过稳定 handle 暴露截图与重置，不把图表实例交给 Frame。
- Frame 只在 panel 密度渲染导出菜单，统一处理失败通知，并把当前 legend 格式器传给可访问层。
- 可访问层只渲染最近 20 根 bars，选中 bar 清除后恢复最新 bar 摘要。

### 实施步骤

1. 增加导出纯函数测试，锁定文件名、时间、空值、转义、顺序和 50,000 根上限。
2. 收敛 `FinancialChartHandle`，接入 Controller 截图并锁定单实例与命令调用。
3. 实现工作台导出菜单、主题铺底、Blob 下载和本地化失败反馈。
4. 实现可访问摘要与最多 20 行的数据表，补齐中英文按钮、表头和状态文案。
5. 运行相关组件测试、完整前端类型检查、lint 和测试；若真实 WebView 下载行为无法由静态证据确认，再按运行时调试文档复验。

### 验证标准

- 文件名保留安全的中文与证券标识并移除路径字符；交易日原样输出，盘中时间输出 UTC ISO。
- CSV 固定八列，空值为空单元格，引号、逗号和换行正确转义，超过上限在构造字符串前拒绝。
- PNG 截图不包含十字线，使用当前主题 surface 铺底，并且截图和导出都不改变图表状态。
- screenshot、Canvas 编码或 Blob URL 不可用时显示本地化错误。
- `aria-live` 在标的或显示 bar 变化时更新，十字线离开后恢复最新 bar；数据表最多 20 行。
- compact 密度不渲染导出菜单，panel 密度菜单和全部可访问文案支持英文与简体中文。

### 执行结果

- 新增独立导出模块，安全文件名保留中文证券名称并移除路径字符。CSV 固定输出 `time,open,high,low,close,volume,amount,open_interest`，交易日保持原字符串，盘中时间使用 UTC ISO，空值为空单元格；50,000 根上限在构造字符串前拒绝。
- `FinancialChartController.takeScreenshot()` 明确排除顶层和十字线。`FinancialChartHandle` 已取代 revision 重置桥，统一暴露重置与截图；React 宿主使用当前 `--background` 创建一次性 Canvas 副本，不修改图表 viewport、十字线或 pane 比例。
- Chart Panel 通过项目级紧凑菜单导出 PNG 和 CSV，数据页的 compact 密度不显示导出入口。screenshot、Canvas 编码和 Blob URL 失败都进入现有本地化通知系统。
- `ChartAccessibilityLayer` 为全部密度提供 `aria-live="polite"` 摘要和可聚焦数据表。摘要随标的或显示 bar 更新，十字线离开后恢复最新 bar；表格只渲染最近 20 根并复用 legend 的价格、成交量和交易所时区格式。
- 真实 Tauri WebView 中两个 Chart Panel 均显示导出入口。PNG 与 CSV 实际下载成功，PNG 为当前深色 surface 且不含十字线，CSV 为八列、500 根数据加表头；导出前后图表 DOM 身份、尺寸和 Canvas 尺寸不变。键盘聚焦入口后可用 Space 展开 20 行表格，compact 数据页没有可见导出入口，运行时未发现错误。
- 完整 `pnpm test` 通过 224 个测试文件、1144 个测试，`pnpm check-types` 和 `pnpm lint` 通过；lint 仅保留仓库既有的 25 个 warning 和 2 个 info。本任务没有修改 Rust 或 Python 协议。
