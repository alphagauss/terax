## 当前任务

目标是把现有临时 K 线拆成由 Terax 自己拥有的公共图表内核，为数据管理、独立行情、工作台、回测复盘和模拟交易提供稳定基础。

- 定向检索 OpenTerminalUI 和 shioaji-pro-app 的图表生命周期、历史回填、状态展示和测试，独立选择适合 Terax 的实践。
- 拆分 `FinancialChartController`、纯显示组件、专业外壳和行情 scene，公共 props 不暴露 Alpha API response 或 Lightweight Charts 类型。
- 接入左侧历史分页和 viewport prepend 补偿，保持主题切换、页面隐藏和标的切换时的实例与可见范围不变量。
- 让数据管理页紧凑模式和独立行情页复用同一个公共图表，并通过纯函数、Controller 和 React 测试锁定关键行为。

完成标准：数据管理页与独立行情页使用同一个公共图表实现；历史向左加载不改变用户正在观察的内容；主题、标的和页面可见性变化不会无故重建图表；后续工作台 Chart Panel 可以直接复用行情 scene。
