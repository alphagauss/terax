## 当前任务

目标是在不新增独立行情页的前提下，让公共金融图表使用权威证券元数据呈现价格精度、交易所时区、涨跌颜色、昨收和最新价，并让成交量 pane 的显隐与用户比例在配置变化中稳定。

- 证券详情显式返回时区、涨跌颜色约定、成交量单位和最小价格跳动，前端不维护重复交易所业务表。
- bars 响应使用同一周期、复权和查询锚点返回权威参考收盘价与时间；历史分页保持相同参考值。
- 图表元数据、主题、图表类型和成交量配置变化不得重建 Lightweight Charts 实例或丢失 viewport。
- Chart Panel 严格配置增加成交量显隐与语义 pane 比例，旧配置自动补齐默认值。
- 本任务不实现独立行情页、导出、指标、同步、对比或实时行情。

完成标准：价格轴、legend、昨收与最新价使用一致精度和市场颜色语义；盘中时间按交易所时区显示；成交量 pane 可隐藏、恢复并保存最终比例；紧凑数据页和工作台面板继续复用同一 Scene 与 Controller。

## 当前任务方案

本节是覆盖式临时记录。每次开始新的 Alpha 任务前，必须先用新任务的目标、范围、实施步骤和验证标准完整替换本节，不保留已完成任务方案的历史副本。长期结论和已完成基线同步到长期架构，任务历史由 Git 保存。

详细设计和后续依赖见根目录 [`plan.md`](../../plan.md) 的“任务 2：专业价格、时间与 pane 语义”。本节只记录当前执行范围和实际验证结果。

### 目标与范围

- 扩展证券详情和 bars 协议，将静态证券语义与随查询变化的参考价分开建模。
- 在前端纯函数层统一价格精度、交易所时区格式和市场涨跌色映射，再由 Controller 应用到 chart 与 series。
- Controller 管理昨收线、最新价线、成交量 pane 生命周期和语义比例，不认识 Alpha API 或工作台持久化。
- 数据页继续固定显示成交量和默认比例；Chart Panel 从严格配置读取、保存成交量显隐和 pane 比例。

### 实施步骤

1. 增加后端协议测试，扩展证券元数据和 bars 参考价响应并锁定分页一致性。
2. 增加价格精度、时区和 palette 纯函数测试，再把元数据、参考价与显式最新价线接入 Controller。
3. 实现成交量 series 的隐藏、迁移和恢复，以及语义 pane 比例的读取、应用和 pointerup 单次提交。
4. 扩展 Chart Panel 严格配置、旧配置迁移、中英文资源和 Scene/Frame/Controller 测试。
5. 在真实 Tauri WebView 中验证最小面板、8:2 比例、手动调整、显隐恢复及主题、标的、周期切换，再运行完整前端检查与相关 Alpha 后端测试。

### 验证标准

- 非法或缺失 `price_tick` 有界降级；常见十进制和 0.25、0.05 等 tick 得到正确精度。
- 盘中刻度格式不受 WebView 系统时区影响；日线和周线继续使用无时区交易日。
- 昨收缺失、为零和存在时的 price line 生命周期正确，最新价颜色与市场约定一致。
- 元数据、主题、图表类型和数据键变化不重建 chart；成交量显隐不丢 bars 或重置时间范围。
- pointer 拖动期间不写共享状态，结束后仅在比例变化时提交一次语义比例。
- 旧 Chart Panel 配置恢复默认成交量和 8:2 比例，新增文案同步提供英文与简体中文。

### 执行结果

- Alpha 已提供图表消费所需的市场元数据、`reference_close` 和 `reference_time`；具体 Python 协议与存储语义见 [Alpha API 协议](../../alpha/docs/api-contracts.md) 和 [行情数据与存储](../../alpha/docs/market-data.md)。前端详情 schema 把 `price_tick` 转换为有界价格精度。
- `FinancialChartController` 已在原实例上应用 `priceFormat`、交易所时区格式、市场 palette、昨收线和显式最新价线。蜡烛、OHLC、成交量和最新价线使用一致方向色，主题、标的、复权和图表类型切换不重建宿主。
- Chart Panel 严格配置已增加 `showVolume` 和语义 `paneRatios`，旧 `{}` 补齐成交量与 8:2。隐藏成交量时先隐藏 series 再迁入主 pane，恢复时创建辅助 pane 并还原用户比例；过矮宿主临时使用主图优先的 8:2，但不覆盖用户在正常高度保存的比例。
- pane 拖动只改变 Lightweight Charts DOM。真实 WebView 中拖动期间 Canvas 比例已经变化而共享配置仍保持旧值，pointerup 后才提交一次最终比例；隐藏、显示、最小 `minH=8`、主题、标的和复权切换均通过同一宿主复验。当前真实数据只声明日线，因此没有制造临时行情数据验证周期切换；完整查询键、时区和单实例路径由自动化测试覆盖。
- 完整 `pnpm test` 通过 222 个测试文件、1131 个测试，`pnpm check-types` 和 `pnpm lint` 通过，lint 仅保留既有 warning 和 info。Alpha 相关路由与元数据测试 19 个全部通过；Alpha 全量 Python 测试为 200 通过、2 跳过，当前量化环境缺少 `pytest-asyncio`，对应的既有异步容器测试改用 `asyncio.run()` 直接执行并通过。
