## 当前任务

目标是在当前 Alpha 工作台 Chart Panel 内添加最多 3 个对比标的，把主标的与对比标的按共同有效起点归一为相对收益线，并显示在不影响主价格轴的左侧百分比轴上。

- 主图有界历史仍决定查询起止范围；对比标的只执行 `start + end` 范围查询，不建立独立历史分页。
- 对比查询最多读取 5,000 根。主图已加载范围更长时只比较最新 5,000 根，并显式展示局部覆盖。
- 归一化只使用每个序列在共同有效起点当日或之后的第一条有效 close，不填补缺失交易日，不使用最近值伪装精确十字线值。
- 每个对比查询、空数据和零基准独立降级，不影响主行情和其他对比线。
- 对比配置只属于工作台 Chart Panel；紧凑数据页不显示入口，也不产生对比查询。

完成标准：用户可以添加、删除和改色最多 3 个对比标的；主标的与对比线使用同一图表实例、独立左侧百分比轴和同一十字线快照；未配置对比时不创建额外 series、不发请求。

## 当前任务方案

本节是覆盖式临时记录。每次开始新的 Alpha 任务前，必须先用新任务的目标、范围、实施步骤和验证标准完整替换本节，不保留已完成任务方案的历史副本。长期结论和已完成基线同步到长期架构，任务历史由 Git 保存。

长期边界见 [Alpha 综合量化工作站](./alpha-quant-workstation.md) 的“公共金融图表内核”和“前端消费的行情协议”。本节只记录任务 7 的前端查询、纯归一化、Controller、Chart Panel 配置和真实 Tauri 验证范围；现有 Alpha `/bars` 范围查询已经满足需求，本任务不修改 Python、Rust 或行情 API。

### 目标与范围

- 只在 `panel` density 和存在 `onComparisonsChange` 时提供对比管理入口；`compact` density 保持原行为。
- Chart Panel 配置新增严格、最多 3 项且标的不重复的 `comparisons`；排除主标的由 Scene 和选择器在运行时共同保证。当前开发阶段不增加配置版本或迁移分支。
- 对比查询键包含标的、周期、复权、实际起止时间和有界 limit；主图 prepend 后范围自然扩展，相同查询由 React Query 复用。
- 归一化结果保持引擎无关，Controller 只消费已计算的百分比点，并按标的 diff 复用 line series。
- 主标的相对收益线使用主题强调色；对比线使用有界调色板内的持久颜色。所有相对收益线共用左侧百分比轴。
- 对比 legend 与指标 legend 复用现有唯一十字线订阅和同一帧快照；没有精确同时间点时显示空值。

### 实施步骤

1. 先为共同起点归一化、非法 close、重复时间、缺失交易日、零基准和不同长度补纯函数测试。
2. 扩展 Chart Panel 配置 schema 和测试，锁定最多 3 项、唯一标的、合法颜色及默认空数组，不增加版本兼容代码。
3. 在 Scene 中按主图实际范围并行执行独立对比查询，限制 5,000 根并生成局部 loading、error、empty、zero-base 和 partial 状态。
4. 为 Controller 增加主标的相对收益线与对比 line registry，按标的 diff 增删和改色，统一输出十字线对比值。
5. 增加懒加载证券搜索管理对话框和紧凑 legend，桥接 Chart Panel 配置并补齐中英文文案。
6. 运行相关测试及完整前端 lint、类型和测试检查；在真实 Tauri 单图面板验证 3 个不同价格量级标的、主题、历史扩展、局部状态、实例身份和配置恢复。

### 验证标准

- 未配置对比时没有 `/bars start + end` 请求、证券详情请求、对比 series 或左轴。
- 共同有效起点使用所有有效序列首时间的最大值；各序列以该时间或之后第一条 close 为 0%，不跨缺失日期补点。
- 单个对比失败、空数据或零基准只影响自身；其余线和主行情保持可用，并可通过删除或重试恢复。
- 新增、删除、改色、主题切换和历史 prepend 不重建 chart，不重置当前 viewport；对比 series 按 vtSymbol 复用。
- 主图超过 5,000 根时查询 limit 仍为 5,000，局部覆盖状态以响应 `actual_start` 为依据显示。
- 十字线对比值与行情和指标在同一个 rAF 回调中提交，且只接受精确同时间点。
- 真实 Tauri 复现约定：给定单图工作台、Modern 主题和一个具有足够日线历史的主标的，添加 3 个不同价格量级且有同周期数据的标的；预期左轴显示百分比、三条线和 legend 可识别，主题切换与向左加载后仍保持图表 DOM 和主价格 Canvas 身份，删除与改色即时生效，小面板工具栏无关键控件遮挡。

### 执行结果

- 新增引擎无关的对比归一化纯函数。所有成功序列先过滤非法 close、按时间排序并让重复时间保留最后值，再以最晚首点作为共同起点；每个序列使用该时间或之后的第一条 close 归一为 0%，缺失交易日不补点，空数据和零基准返回结构化错误。
- Chart Panel 配置新增最多 3 项的 `comparisons`，标的统一归一为 `代码.交易所`、禁止重复，颜色只接受六位十六进制；缺失字段使用空数组，不增加配置版本或迁移代码。周期、pane、指标和对比更新都保留彼此配置，工作台状态解析测试锁定对比项可以持久化恢复。
- Scene 只在面板可见、主图有实际范围且存在对比配置时发起查询。每个标的使用独立查询键和 `start + end`，limit 取主图已加载数量并硬限制为 5,000；同范围命中 React Query cache，prepend 扩展实际起点后才请求新区间。证券详情只用于名称，失败时回退 `vtSymbol`；主标的、重复项和单项查询失败不会产生错误串扰。
- Controller 持有主标的相对收益线和按 `vtSymbol` diff 的对比 line registry。所有线使用可见左价格轴和自定义百分比格式，右价格轴不变；新增、改色和删除复用 chart 与既有 series，删除最后一个对比时同时移除全部相对收益线并隐藏左轴。未配置对比的快速路径不调用额外图表选项。
- 对比 legend 与指标 legend 共用唯一 `subscribeCrosshairMove` 和同一个 rAF snapshot；正常 pointer 直接读取精确 seriesData，同步十字线使用二分查找精确时间，不做最近值回退。主标的和每个对比标的都显示名称、代码、颜色和百分比；单项 loading、error、empty、zero-base、partial 可见，error 可单独重试，任意项可删除或在懒加载 Dialog 中改色。
- 证券搜索 Dialog 只在工作台入口首次打开时加载，复用 Alpha 证券目录并按当前周期过滤，排除主标的和已选标的，达到 3 项后禁用新增。入口放入现有更多操作菜单，数据页没有入口或请求。中英文资源保持一致。
- Alpha 范围测试为 35 个文件、171 个测试；完整前端为 232 个文件、1,192 个测试。`pnpm check-types`、`pnpm lint`、`pnpm analyze:eager` 和完整测试通过；lint 仅保留仓库既有 25 个 warning 与 2 个 info。
- 真实 Tauri WebView 使用主标的 `000001.SZSE`，添加 `600000.SSE`、`000300.SSE` 和 `300750.SZSE`。三项均进入 ready，主图左右价格轴各保持 66 px，快速十字线移动后四条相对收益在同一 legend 快照更新。改色、删除、深浅主题切换和向左加载历史期间 chart 宿主与主绘制 Canvas 身份保持；历史扩展后共同基准随新区间更新，删除最后一项后 legend 与左轴同时消失。双图模板中 588 px 面板头部 `clientWidth` 与 `scrollWidth` 相等，对比入口仍在更多菜单；Dialog 复验只显示本地化关闭操作，没有生成组件的默认英文文案。
- 调试创建的工作台、颜色、主题和模板状态均通过逐字节恢复共享配置撤销。debug Terax、Cargo、Vite 和 WebView2 仅按本次记录的 PID 停止，release Terax 进程未触碰；端口 1420、9223 已释放，配置备份哈希与恢复后文件一致，临时备份和 WebView 目录已删除。
