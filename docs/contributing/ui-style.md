# 桌面 UI 样式

Terax 使用紧凑桌面密度，业务页面复用公共控件与语义 token。尺寸和样式定义以 `components/controls/`、`components/layout/`、`components/settings/` 与 `styles/globals.css` 为准，菜单使用 `components/menu/`。

## 展示规则

- Hugeicons 使用包公开的单图标子路径导入，避免开发模式加载整套图标数据；保持现有图标形状、名称和交互不变。

- 页面只声明布局与不同于默认的规格，不重复覆盖控件字号、圆角、焦点和动画；新通用规格放公共入口。
- 普通次要操作使用 `@/components/controls/button` 的 `ghost`：默认次要文字色，悬停和菜单打开时正文文字色，背景沿用统一 ghost 反馈，图标继承文字色。`ghost-warning` 保留警示琥珀色；`ghost-destructive` 始终显示危险色；`ghost-destructive-hover` 默认次要文字色、悬停和打开时危险色；有底色的危险操作继续用 `destructive`。业务不重复声明这些默认颜色、悬停色和打开色，尺寸用 `size`，布局由调用方提供。持续选中外观由业务明确选择现有 `secondary`、`outline` 等规格并提供 `aria-pressed`，不把当前模型、搜索类别或统计范围的取值自动当作视觉选中。业务包装可以组合图标、文字、菜单及特殊状态；已有规格不能表达的业务效果可以自定义，复用需求成立后再提取到公共控件。不要为同一常规效果新增按钮包装或颜色覆盖。
- 普通悬停提示统一从 `@/components/controls/tooltip` 导入：简单文本使用 `Hint`，复合详情使用 `Tooltip`、`TooltipTrigger` 和 `TooltipContent`。窗口提供默认分组，独立面板可用 `TooltipProvider` 隔离分组；仅鼠标悬停触发，首次悬停 800ms 显示，关闭后 500ms 内同组切换免等待；聚焦、焦点恢复不触发，点击和窗口失活关闭提示，已展开弹层的入口不重复显示提示。业务代码仅声明内容和必要的定位、布局，不覆盖延迟、配色、字号、圆角和动效，不使用原生 `title` 充当提示。浅色主题浅底深字，深色主题深底浅字。iframe 的可访问标题、编辑器补全与诊断、图表数据浮层不属于普通悬停提示。
- 普通设置使用组内分隔行，供应商、Agent、SSH 连接等独立实体保留卡片或列表详情。同字段多选项使用一个容器内的勾选行，不逐项套卡片。
- 已有独立悬停面板的入口不叠加文字提示，例如 AI 用量入口保留用量详情面板，不再设置 Tooltip 或原生 `title`。
- 父容器拥有间距；页面标题、组标题和字段复用已有布局组件。布局组件不持有配置、提交或校验规则。
- 对话框和浮窗仅在标题栏支持拖动时使用独立的 card 底色；固定弹层与内容同底色，有标题时用细分割线，无标题时仅保留操作按钮，不占用空标题栏。弹层标题区和关闭按钮点击区域比主窗口、辅助窗口更紧凑，文字与图标大小不变，带说明的标题区自然增高；关闭反馈复用公共样式。页内浮窗显式启用拖动，标题栏悬停和拖动时均显示普通箭头光标，按钮不触发拖动；位置限制在所属页内，隐藏保留位置，宿主缩小时收拢，关闭释放展示位置。
- 小字号说明使用语义文字色，不叠加透明度进一步弱化；图表、终端和表格保留自身密度。
- 菜单触发器与设置导航关闭后不留下额外焦点光晕，选中由背景表示；输入焦点默认使用中性边框，需要强调聚焦时通过公共输入控件显式启用与搜索侧边栏一致的主题强调色细边框，不增加外圈光晕；主要操作与错误保留语义色。
- 设置顶部导航空间足够时居中，溢出时起点可达，滚轮横向滚动并保持当前项可见；只在该视口使用原生平滑滚动，reduced motion 直接定位。

文件拖放统一使用主题强调色的 1px 内侧边框，贴合实际接收区域并沿用其圆角，不遮盖或模糊内容、不改变布局尺寸。文件树标记实际目标目录行或根目录内容区；终端标记所在工作区分组的内容区域外框（不包含标签栏，禅模式沿用同一内容边界），不跟随内部终端反向缩放区域；输入框标记自身外框。不可接收时不显示接收边框，松开后按需提示原因。

## 错误提示

操作失败通过统一错误入口报告，在当前窗口右上角显示错误浮层。主窗口和辅助 WebView 共用组件，各自保存当前窗口内的最近错误，不跨窗口广播或持久化。成功、信息和已有审批提示继续使用右下角通知。

普通错误累计可见 8 秒后收起；悬停、焦点进入、详情展开及窗口失焦或隐藏时暂停。临时提醒右上角纵向显示“关闭”和“忽略”：点击摘要或关闭按钮收起提醒并保留历史，忽略则同时移除本条历史；选择文字和操作按钮不触发摘要关闭。历史卡片右上角只提供忽略，移除时保留退出画面至动画结束，其余卡片同步补位。关闭与忽略不取消任务、不清除业务失败状态；字段校验和页面加载、会话失败等持续状态仍由所属页面展示。

错误浮层最多同时展示 3 条，额外错误进入最近记录；短时间内相同来源、标题和原因的错误合并计数，已收起的重复错误不反复弹出。最近记录最多保留 50 条，并保留仍在展示的错误。标题栏仅在有记录时显示错误图标，点击展开列表；打开列表即结束当前所有临时提醒，查看期间的新错误只加入列表，收起后不恢复提醒。点击列表外、键盘焦点移出、按 Escape 或窗口失焦、隐藏时收起列表，内部操作与菜单不触发外部关闭。模态框内 Escape 优先收起错误列表，输入法取消不关闭列表或底层对话框；清空同时收起浮层、列表并隐藏图标，不影响任务。详情操作行位于摘要上方，展开时保留摘要和按钮位置，诊断向下揭示、收起时反向过渡，后续卡片与独立背景边框同步运动；长诊断限制在可用视口内并独立滚动。详情和复制使用同一份脱敏诊断，复制失败在卡片内反馈，避免递归报错。弹窗打开时错误浮层进入该弹窗的焦点范围；支持浏览器顶层浮层的 WebView 保持窗口右上角定位，其他系统 WebView 在当前弹窗右上角显示。

原位提示与浮层使用同一次操作或任务运行的身份关联，不按文案合并不同运行。关闭浮层、忽略或清空历史保留原位提示；原位关闭则隐藏本次提示并收起关联浮层，历史继续保留。关闭状态属于当前窗口内的运行身份，页面切换、重挂载和重复快照不能恢复提示；新一次失败使用新身份。业务恢复时收起对应提示和浮层，组件卸载不代表业务恢复。

原位关闭默认不提供：字段校验、页面不可用等持续状态保留原因，已有独立失败状态的任务行可关闭补充提示。有额外诊断时提供详情入口，直接定位并展开同一条历史，不增加发生次数；记录已清空或淘汰时，只在用户主动查看时恢复历史，不重新弹窗。业务状态与恢复动作仍由业务模块拥有，历史容量和提示关闭不改变任务或字段有效性。

## 复制与右键菜单

文件和文件夹菜单按打开与定位、复制、常规文件操作、场景与传输操作、收尾操作排序；已有复制相对路径的入口中，复制路径与复制相对路径始终相邻且顺序固定。类型或环境专属操作不插入复制组之前，打开能力本身除外。删除和属性位于底部，属性最后；文件标签沿用打开与定位、复制、场景操作的顺序，之后排列标签布局操作，关闭最后。

项目定义的复制按钮和自定义右键菜单使用统一剪贴板入口，按内容保留纯文本、图片或 HTML 与纯文本双格式，不把图片或富文本统一降为文本。Windows 与 Linux 的主动复制通过 Tauri 剪贴板插件写入系统剪贴板；Windows 应能进入已启用的 Win+V 历史，具体收录仍受系统格式与大小限制。插件写入失败不得静默回退网页写入并提示成功。

Windows 主窗口的普通页面文本选区通过复制事件接入原生写入，覆盖 Ctrl+C 和 WebView 菜单的选区“复制”，保留文本与 HTML 结构，不拦截快捷键本身。Windows 主窗口和辅助窗口的普通输入框复制实际选区；CodeMirror 复用编辑器生成的文本，保留整行复制、多选区和粘贴状态；复制适配不改动剪切、粘贴与历史记录，密码字段保留原生复制。Shell 输入框遵循智能复制设置：非 macOS 开启智能复制且有选区时 Ctrl+C 复制，其余情况保持中断与清空。

主窗口与辅助窗口提供公共补缺菜单：已有业务菜单优先，普通页面按目标提供选区复制、图片复制与另存为、链接地址复制，没有可用动作的空白处不显示菜单。打开时保存选区和链接；图片复制前确认目标仍在页面且来源未变。另存为复用已有图片资源与保存流程，保留原始格式和字节；成功、取消或失败后均释放本次准备的临时资源。弹窗内的菜单挂载到该弹窗内，避免焦点与点击被弹窗拦截。

编辑区域的菜单外观统一目前仅覆盖 Windows 主窗口和已注册的辅助窗口。菜单由 Terax 绘制，文案跟随应用语言，快捷键保持原绑定。普通输入框的命令可用状态与执行委托 WebView2；这里的“原生命令”指 WebView2 编辑命令，与上述剪贴板插件写入是不同入口。CodeMirror 的撤销、重做读取并调用自身事务历史，其他菜单动作继续委托 WebView2，不维护第二份编辑历史。

菜单关闭后恢复编辑目标再执行命令；委托请求按窗口与连接隔离，取消、超时、导航或销毁均释放，过期请求不得执行。密码字段、终端业务菜单与内嵌网页不接管。macOS、Linux 尚未接入这套编辑菜单，继续由各自 WebView 绘制和执行默认编辑菜单；已有项目复制按钮和普通页面补缺菜单仍按上文规则工作。不监听或重写其他应用的系统剪贴板。

## 活动栏导航

主活动栏同时承载侧边栏入口和打开工作页的应用入口。主侧边栏展开时，选中状态优先反映正在展示的侧栏；收起时，选中当前聚焦工作页对应的应用入口，无对应入口则无选中项。应用入口通过声明对应的工作页类型参与匹配，新增应用沿用同一规则。打开侧栏不切走当前工作页，高亮也不记录最后一次点击。

## 布局

顶层 SplitView 只使用 react-resizable-panels 和稳定 ID。拖动期间用 DOM ref 与 transform 更新指示器，仅在 onLayoutChanged 确认交互结束后保存尺寸。

业务页面统一以面板作为空间分配单位：图表、资料、资讯、订单等完整业务区域分别属于面板，内部字段和控件不提供独立拉伸。固定分区使用公共 `SplitLayout`、`SplitPanel` 和 `ResizeHandle`，支持水平、垂直嵌套；容器分配空间，面板内容负责滚动、换行和固定阅读密度。每组保留一个弹性面板吸收剩余空间，其余面板使用像素尺寸；调用方根据各面板最低可用尺寸设置容器下限及溢出策略。

分隔条使用 `ew-resize` / `ns-resize` 双向箭头光标，保持 Windows 系统光标的清晰度。分隔条统一支持拖动预览、松手提交、方向键调整、Home/End 到边界、双击恢复默认和 Escape 取消拖动。业务声明稳定面板 ID、默认尺寸和上下限，不复制指针交互。面板收起保留内容实例；侧栏内容保留最后一次有效展示尺寸，不随外层收起到零宽而重排，恢复时接入实际宿主尺寸。业务另行关闭展示查询和订阅。公共布局层不依赖业务模块或持久化文件，通过提交回调交由业务按视图、分区精确保存尺寸和展开状态；不保存查询结果，不因容器临时变小覆盖用户偏好。

## 动画

- 动画用于操作反馈、状态提示或空间关系，复用现有 motion 与时长 token。实时数据更新、输入和加载完成不重新触发页面入场；性能优化优先保持既有尺寸、速度、节奏与亮度，不默认以降帧或移除必要前台动画替代实现优化。
- 普通卡片列表、网格和局部操作区的布局补位使用公共 `LayoutFlow`，复用原有 flex、grid 或列表语义，只测量直接子项，直接子项的样式换序与语义隐藏也会同步；父容器为作用域分配可用宽度。竖向、横向和换行位移与错误卡片共用布局引擎及播放会话；新项直接定位，已有项从当前视觉位置补位，不缩放文字或重挂载内容。首次显示、隐藏后恢复、作用域及祖先滚动或容器宽度变化只建立新基线，减少动态效果时直接提交。窗口隐藏时暂停观察；保留挂载的隐藏宿主须传入 `active={false}`。`LayoutFlow` 拥有直接子项的位移，内部 `ContentReveal` 只协调该子项内的后续内容，避免双重补位；不要把它包在已有虚拟化、拖动定位或实时排序的内容外层，也不要嵌套作用域重复驱动同一层内容。
- 持续动画和展开、折叠、切换等过渡都应尽可能复用已绘制内容，避免变化过程中逐帧重排、重绘。优先在稳定外壳上使用 `transform`、`opacity`，保持内部文字、图形和内容尺寸稳定；使用这些属性、CSS 动画或公共动画封装本身不保证低开销。
- 布局提交与视觉过渡分离。目录开关、侧边栏分组折叠等操作，真实尺寸在状态切换边界提交，视觉过程优先用位移、透明度或固定尺寸内容的揭示效果表达；承载长文档、编辑器、终端、虚拟列表或图谱的容器不逐帧过渡宽高、`max-height`、`flex-grow` 等布局尺寸，也不缩放文字或克隆昂贵内容树来模拟过渡。动画很短或列表已经虚拟化，都不能豁免这项约束。
- 模型参数、提交改动和侧边栏分组使用空间揭示：新内容立即以最终尺寸呈现，裁剪边界与后续内容同步移动，不等待展开后再淡入；等高模型切换直接更新内容。普通文档流宿主用 `data-reveal-boundary` 声明同列布局范围，后续内容的位移不越过该边界。虚拟列表保留虚拟化，视觉距离限制在视口内；新进入虚拟范围的后续行从原边界进入，收起仅暂留已有展示行至过渡结束。
- 长内容的揭示进度以实际滚动视口为界：先将起止边界限制在可见范围内，再生成裁剪和后续内容的位移动画；普通列表与虚拟列表遵循同一规则并复用公共揭示执行器。只限制裁剪层大小、仍按完整内容高度推进，会让展开在前几帧铺满可见区域，看起来像没有动画；也不能用窗口高度替代较小的面板视口。后续标题和内容沿用同一边界进度，真实布局仍保留完整高度。过渡期间滚动使原边界失效时，结束动画并恢复完整内容，避免新进入视口的行被旧裁剪遮挡。
- 布局变化不重复驱动内容工作。避免尺寸观测和动画帧反复触发解析、高亮、列表测量、图形布局、数据请求或持久化；必要的测量在布局边界收敛，拖动重内容区域的分隔线优先移动预览指示，确认后提交尺寸。保留内容实例、阅读锚点、滚动位置和焦点，不能用重挂载抵消布局问题。
- 将必要的重绘限制在局部。小范围悬停配色等反馈可以重绘，但不应牵连整棵内容树或整张 WebView；裁切、绘制隔离和虚拟化也不能代替验证。遮罩、渐变和图层尺寸应有界，不随被省略或不可见的内容无限增长；不全局添加 `will-change` 或强制提升图层，只在真实对照证明有收益时局部使用并及时释放。
- 隐藏或折叠后不只设置透明度，还应停止无用的展示订阅、渐进更新、计时与动画，释放不再需要的展示资源；可见的聚合运行指示仍可提示后台任务。隐藏内容不得继续参与点击或键盘导航，装饰副本不得重复可访问文本或干扰文字选择。展示生命周期不得停止业务运行、审批或保存。
- 动画可取消，快速反向切换从当前视觉状态继续，不叠加旧动画；结束、取消或卸载时清理临时样式、图层、监听和帧任务。`prefers-reduced-motion` 下直接呈现最终布局与静态结果。明确列出需要过渡的属性，不使用 `transition-all`、Document View Transition、`flushSync`、全局平滑滚动或逐帧业务 React 状态。

涉及昂贵内容的布局过渡、持续动画的新增和性能改造，按 [测试指南](testing.md) 选择验证方式；确需运行时取证时按 [运行时调试](ui-runtime-debugging.md) 检查实际渲染路径与收益，未实测不宣称性能提升。颜色遵循 [主题](themes.md)。
