# 桌面 UI 样式规范

Terax 的设置、对话框和业务页面采用紧凑桌面密度。相同用途的控件共享默认外观，业务模块只管理数据和行为。主题颜色继续遵循 [主题规范](./themes.md)。

## 字体与尺寸

以下尺寸对应 100% 应用缩放。界面延续 Inter，并使用系统中文字体回退；代码和路径使用等宽字体。

| 语义 | 字号 / 行高 | 字重 |
| --- | --- | --- |
| 页面标题 | 18px / 24px | 600 |
| 分组标题、设置项标题 | 12.5px / 18px | 500 |
| 正文、字段标签 | 12px / 18px | 正文 400，标签 500 |
| 单行控件 | 12px / 16px | 沿用控件语义 |
| 辅助说明 | 11px / 16px | 400 |

有意义的说明使用 `muted-foreground`，不额外降低文字透明度。图表数值、徽标和终端内容有各自的信息密度，不由页面表单字号覆盖。

## 控件入口

业务代码统一从 `@/components/controls/` 导入 Button、Input、Textarea 和 Select。Biome 禁止业务代码直接导入这些 registry 控件。`components/ui/` 和 `components/ai-elements/` 仍由注册表管理，只有项目包装层负责调整其业务默认样式。

业务 Dialog 和 AlertDialog 同样从 `components/controls/` 导入。对话框使用 16px 内边距和区块间距、14px 标题，并保持操作按钮横向排列；有关闭按钮时标题区预留其宽度。确认与取消复用公共 Button，原有弹层和键盘行为由基础组件管理。

- 输入框和默认按钮、选择器高 32px；按钮和选择器的 `sm` 为 28px，用于工具栏。
- 按钮 `xs` 为 24px，只用于面板标题栏或行内嵌入操作；`lg` 为 36px。图标按钮使用对应的 `icon`、`icon-sm`、`icon-xs` 和 `icon-lg`。
- 控件圆角使用 `rounded-md`，分组和下拉表面使用 `rounded-lg`，不在页面中重写圆角。
- 调用方可以声明宽度、排列、文本对齐和等宽字体；字号、基础内边距、焦点与动效由控件拥有。专用搜索栏可以声明嵌入背景、图标预留空间等布局差异。
- 不为取得默认样式重复添加 `h-8`、`text-xs`、`rounded-md` 等 class。需要不同尺寸时先使用组件已有尺寸属性；新的通用规格必须在公共入口定义。
- 保留键盘焦点管理、禁用和错误状态，不要使操作仅能通过 hover 发现。
- 菜单触发器和设置导航保持无额外焦点边框：打开菜单后点击空白处关闭，不因 Radix 恢复焦点而留下描边或光晕。标签选中由背景表示；文本输入的编辑焦点使用中性边框，开关开启、复选框勾选、主操作与错误状态继续使用各自语义颜色。

## 间距与分组

| 用途 | 标准 |
| --- | --- |
| 页面内边距 | `p-page`，24px；窄窗口使用 `p-4`，16px |
| 页面标题到内容、组间距 | `gap-section`，16px |
| 组标题到内容 | `gap-2`，8px |
| 表单字段间距 | `gap-field`，12px |
| 标签到控件 | `gap-1`，4px |
| 同行操作间距 | 默认 `gap-2`，8px；紧凑操作按按钮尺寸使用 6px 或 4px |
| 设置行内边距 | 水平 12px，垂直 8px |

父容器拥有子项之间的间距，子组件不自带外边距。语义间距变量定义在 `src/styles/globals.css`。

- `PageHeader` 统一页面标题、说明与可选操作；`SectionHeading` 统一分组标题。
- `SettingGroup` 为同组设置绘制一层边框和背景，直接子行之间使用分隔线。单独一项也必须放入分组，不重新启用独立设置行卡片。
- `SettingRow` 只排列说明与控件。容器宽度不足 30rem 时改为上下排列，长说明自然换行，控件不超出所在行。
- `FormField` 用于纵向字段。提供 `htmlFor` 时关联真实控件 id；已有 `aria-label` 的复合控件可只展示字段说明。错误说明由业务表单提供。
- 供应商、Agent、SSH 连接等独立实体继续使用卡片或列表详情结构，卡片内复用同一套控件和字段规则。
- 同一字段内的多选项（例如智能体工具权限）使用一个容器内的勾选行，行间只有分隔线。保留整行点击和辅助说明，不为每个选项创建独立卡片；这种局部 JSX 不需要另建列表框架。

布局组件不读取设置、不生成表单 schema、不推断子组件类型、不持有提交或校验状态。重复的简单 JSX 可以保留在业务数据流附近，不为了统一几个 class 建立通用页面引擎。

## 动效

复用现有语义时长：反馈 100ms、控件 160ms、面板 150ms、表面 240ms。普通控件使用 `duration-control ease-standard`，页面切换复用 `terax-tab-in` 的轻淡入；输入、加载完成和实时数据更新不重新触发页面入场。

不新增动画依赖或逐帧 React 状态。图表、表格、编辑器与终端不做尺寸过渡。遵循现有 reduced motion 规则，拖动期间不添加几何动画。

设置顶部导航在独立的横向视口内滚动；空间足够时整组居中，溢出时保留可达的滚动起点。普通滚轮映射为横向滚动，切换标签或标签列表尺寸改变后确保当前项可见。只有这个视口启用浏览器原生平滑滚动，reduced motion 时直接定位，不启用全局平滑滚动。

## 验证与维护

迁移公共组件时，同步删除调用方的默认样式覆盖与被替换的旧入口。检查常规设置、模型表单和一个数据页面，并覆盖窄容器、长文案、键盘焦点、错误与禁用状态。跨页面改动运行完整前端检查；涉及实际布局时按 [运行时调试指南](./ui-runtime-debugging.md) 验证。

不添加检查 class 字符串、透传或常量拼装的恒等式测试；业务行为由既有测试锁定，外观通过实际计算样式和页面检查验证。
