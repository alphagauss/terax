# 桌面 UI 样式

Terax 使用紧凑桌面密度，业务页面复用公共控件与语义 token。尺寸和样式定义以 `components/controls/`、`components/layout/`、`components/settings/` 与 `styles/globals.css` 为准，菜单使用 `components/menu/`。

## 展示规则

- 页面只声明布局与不同于默认的规格，不重复覆盖控件字号、圆角、焦点和动画；新通用规格放公共入口。
- 普通悬停提示统一从 `@/components/controls/tooltip` 导入：简单文本使用 `Hint`，复合详情使用 `Tooltip`、`TooltipTrigger` 和 `TooltipContent`。窗口提供默认分组，独立面板可用 `TooltipProvider` 隔离分组；首次悬停 800ms 显示，关闭后 500ms 内同组切换免等待。业务代码仅声明内容和必要的定位、布局，不覆盖延迟、配色、字号、圆角和动效，不使用原生 `title` 充当提示。浅色主题浅底深字，深色主题深底浅字。iframe 的可访问标题、编辑器补全与诊断、图表数据浮层不属于普通悬停提示。
- 普通设置使用组内分隔行，供应商、Agent、SSH 连接等独立实体保留卡片或列表详情。同字段多选项使用一个容器内的勾选行，不逐项套卡片。
- 已有独立悬停面板的入口不叠加文字提示，例如 AI 用量入口保留用量详情面板，不再设置 Tooltip 或原生 `title`。
- 父容器拥有间距；页面标题、组标题和字段复用已有布局组件。布局组件不持有配置、提交或校验规则。
- 小字号说明使用语义文字色，不叠加透明度进一步弱化；图表、终端和表格保留自身密度。
- 菜单触发器与设置导航关闭后不留下额外焦点光晕，选中由背景表示；输入焦点使用中性边框，主要操作与错误保留语义色。
- 设置顶部导航空间足够时居中，溢出时起点可达，滚轮横向滚动并保持当前项可见；只在该视口使用原生平滑滚动，reduced motion 直接定位。

文件拖放统一使用主题强调色的 1px 内侧边框，贴合实际接收区域并沿用其圆角，不遮盖或模糊内容、不改变布局尺寸。文件树标记实际目标目录行或根目录内容区；终端标记所在工作区分组的内容区域外框（不包含标签栏，禅模式沿用同一内容边界），不跟随内部终端反向缩放区域；输入框标记自身外框。不可接收时不显示接收边框，松开后按需提示原因。

## 布局

顶层 SplitView 只使用 react-resizable-panels 和稳定 ID。拖动期间用 DOM ref 与 transform 更新指示器，仅在 onLayoutChanged 确认交互结束后保存尺寸。

## 动画

- 动画用于操作反馈、状态提示或空间关系，复用现有 motion 与时长 token。实时数据更新、输入和加载完成不重新触发页面入场；性能优化优先保持既有尺寸、速度、节奏与亮度，不默认以降帧或移除必要前台动画替代实现优化。
- 持续动画和展开、折叠、切换等过渡都应尽可能复用已绘制内容，避免变化过程中逐帧重排、重绘。优先在稳定外壳上使用 `transform`、`opacity`，保持内部文字、图形和内容尺寸稳定；使用这些属性、CSS 动画或公共动画封装本身不保证低开销。
- 布局提交与视觉过渡分离。目录开关、侧边栏分组折叠等操作，真实尺寸在状态切换边界提交，视觉过程优先用位移、透明度或固定尺寸内容的揭示效果表达；承载长文档、编辑器、终端、虚拟列表或图谱的容器不逐帧过渡宽高、`max-height`、`flex-grow` 等布局尺寸，也不缩放文字或克隆昂贵内容树来模拟过渡。动画很短或列表已经虚拟化，都不能豁免这项约束。
- 布局变化不重复驱动内容工作。避免尺寸观测和动画帧反复触发解析、高亮、列表测量、图形布局、数据请求或持久化；必要的测量在布局边界收敛，拖动重内容区域的分隔线优先移动预览指示，确认后提交尺寸。保留内容实例、阅读锚点、滚动位置和焦点，不能用重挂载抵消布局问题。
- 将必要的重绘限制在局部。小范围悬停配色等反馈可以重绘，但不应牵连整棵内容树或整张 WebView；裁切、绘制隔离和虚拟化也不能代替验证。遮罩、渐变和图层尺寸应有界，不随被省略或不可见的内容无限增长；不全局添加 `will-change` 或强制提升图层，只在真实对照证明有收益时局部使用并及时释放。
- 隐藏或折叠后不只设置透明度，还应停止无用的展示订阅、渐进更新、计时与动画，释放不再需要的展示资源；可见的聚合运行指示仍可提示后台任务。隐藏内容不得继续参与点击或键盘导航，装饰副本不得重复可访问文本或干扰文字选择。展示生命周期不得停止业务运行、审批或保存。
- 动画可取消，快速反向切换从当前视觉状态继续，不叠加旧动画；结束、取消或卸载时清理临时样式、图层、监听和帧任务。`prefers-reduced-motion` 下直接呈现最终布局与静态结果。明确列出需要过渡的属性，不使用 `transition-all`、Document View Transition、`flushSync`、全局平滑滚动或逐帧业务 React 状态。

涉及昂贵内容的布局过渡、持续动画的新增和性能改造，按 [运行时调试](ui-runtime-debugging.md) 验证实际渲染路径与收益；颜色遵循 [主题](themes.md)。
